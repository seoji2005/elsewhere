# C083 주민 생활 동작: 앉기·사기·서서 대화 (Claude 클라우드 opus)
목적: DIRECTION 첫 목표 "예쁜 작은 거리에서 주민들이 생활하는 장면"의 동작 부분. 지금 주민은 걷기·대기·뛰기만 한다. 애니메이션 라이브러리(assets/manifest.json people 번들, UAL1_Standard.glb)에 이미 Sitting_Enter / Sitting_Idle_Loop / Sitting_Exit / Sitting_Talking_Loop / Interact / PickUp_Table / Idle_Talking_Loop가 있다. 이를 번들에 넣고, 주민이 장소의 상호작용 지점에서 일과에 맞게 앉고(공원 벤치·찻방 자리), 가게 앞에서 사고(Interact), 둘이 마주 서서 대화(Idle_Talking_Loop)하게 한다.
먼저 읽기: AGENTS.md, src/anime/avatar.ts(retarget·mixer), src/render/assets.ts, tools/assets.mjs(clips 필터), assets/manifest.json, src/scene/corner.ts·props.ts(벤치 등 소품 위치), src/sim/npc.ts·src/game/session.ts(주민 위치·일과 — 읽기만), main.ts의 cast=1.
고칠 파일:
- assets/manifest.json (people clips 목록에 위 동작 추가만), src/assets/people.glb (재생성)
- src/anime/avatar.ts (상태별 동작 재생·전환)
- src/scene/spots.ts (새: 장소별 상호작용 지점 데이터 — 벤치·가게 카운터·대화 자리)
- src/main.ts (주민 표시에 연결 몇 줄)
- tests/play/life.mjs (새: 공원 벤치에 앉은 주민·가게 앞 구매 동작 확인)
- src/scene/props.ts (벽을 보던 벤치 방향 1줄 — 마스터 사후 승인)
크기: 큼(≤400줄, 마스터 이유: 번들·동작 상태·지점 데이터·화면 확인을 한 기능으로)
하지 말 것: sim 로직 변경(일과·경제는 그대로, 화면 표현만), 빌드 10240KB 초과(지금 약 9.9MB — 클립 용량 확인), 발이 땅에 안 닿거나 벤치에 파묻히기, 새 npm 패키지.
통과 기준: ?cast=1(또는 기본 화면)에서 낮 시간 공원 벤치에 앉아 있는 주민, 가게 앞에서 Interact하는 주민, 마주 서서 대화하는 두 주민이 스크린샷에 보임(.shots-c083/ 에 jpg ≤4장 커밋), 앉기 진입·이탈이 튀지 않음, play 시나리오 통과. `bash tools/check.sh --card cards/C083.md` PASS(tests/tools/normalize의 Blender 없음 실패만 예외).
