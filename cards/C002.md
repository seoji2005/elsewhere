# C002 에셋 파이프라인

목적: CC0 원본(/home/dev/asset-packs/, 읽기만)에서 "한 모퉁이" 장면에 쓸 것만 폰용으로 줄여 `src/assets/*.glb`로 만든다 (M1-01 준비)
고칠 파일:
- assets/manifest.json, assets/CREDITS.md
- tools/assets.mjs
- src/assets/*.glb
- src/render/assets.ts
- package.json (scripts 칸만)
크기: 보통(≤150줄) — glb는 줄 수에서 빠진다(바이너리)
하지 말 것: 장면 구성(main.ts 수정), 새 패키지, 커밋
통과 기준:
1. manifest.json: 묶음별 원본 목록. city = /home/dev/asset-packs/q-city/Exports/glTF (Godot)/ 의 Building_Small_1, Building_Medium_2_001, Building_Large_2, Street_4Lane, Street_4WayIntersection, Sidewalk_Straight_3m, Sidewalk_Corner_Round_3m, Prop_Bollard, Prop_Planter_Single, Prop_ACUnit, Door_1, Entrance_Concrete_2x1.
   nature = /home/dev/asset-packs/q-nature 에서 가로수 2종, 덤불 1종(실제 파일을 찾아서). cars = /home/dev/asset-packs/k-car-kit 에서 세단·택시·밴.
2. tools/assets.mjs (`npm run assets`): 묶음마다 merge → prune/dedup → 텍스처 최대 512px webp → meshopt → src/assets/<묶음>.glb. 노드 이름은 원본 파일 이름 유지.
3. src/render/assets.ts: GLTFLoader + MeshoptDecoder로 `?url` import한 glb를 불러오는 함수 하나.
4. `bash tools/check.sh --fast --card cards/C002.md` PASS. 보고에 묶음별 glb 크기와 빌드 크기.
