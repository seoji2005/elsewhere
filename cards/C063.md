작업 순서(원칙 그대로):
1. 소체 import → 본 스케일 또는 Lattice로 SD 2.7등신(머리 둥글게 — C059 결과: 얼굴 높이/폭 ≈0.97) → Apply as Rest Pose(셰이프 키 보존 확인: blink·joy·a 값 그대로 동작).
2. 의상: 몸통 상체 복제 → Shrinkwrap → Solidify(offset 1.0) → 소매·밑단 Extrude → Corrective Smooth → Data Transfer 웨이트 = 작업 조끼, 짧은 코트. 하체 복제로 플리츠 스커트. 원본 VRoid 옷 메시는 숨기거나 지운다(클리핑 없게).
3. 타이·머리핀·코트 끈: BezierCurve + bevel/taper → 메시. 머리카락은 소체 보브 유지, 필요하면 앞머리 몇 가닥만 곡선으로 추가.
4. 재질: MToon 평면색(팔레트), 외곽선. 표정·시선·스프링 본(머리·코트 자락) 유지.
5. 검수 루프(필수): 내보내기 전 Cycles CPU 저샘플로 정면·45도·측면·얼굴 클로즈업 4장 PNG를 .shots/c063-<라운드>-<방향>.png로 렌더하고 **멈춰서 마스터에게 경로를 보고**한다. 마스터 피드백을 받아 고치고 다시 렌더 — 최소 2라운드. 마스터가 통과시키면 VRM 내보내기 → 게임 연결 → gha-shots `"model=lise-c" "model=lise-c&cast=1&dist=3.5&pitch=0.12"`.
