# C006 걷기·카메라·건물 앞 상호작용 (플레이 경험, Claude 작업자)

목적: M1-10 앞부분. 폰 가로 화면에서 내 캐릭터로 한 모퉁이 동네를 걸어 다니는 느낌이 좋아야 한다.
고칠 파일:
- src/main.ts, src/scene/corner.ts
- src/player/*.ts, src/ui/*.ts, src/ui/*.css, index.html
- assets/manifest.json, src/assets/people.glb, src/render/assets.ts
- tests/play/*
- tools/assets.mjs (마스터 환경 수정: 동작 필터)
- tools/check.sh (tests/play 시나리오 실행 단계 추가만)
크기: 큼(≤400줄)
하지 말 것: 건물 실내, NPC, 돈·관계 로직, look A/B 재질 변경, 새 패키지, 커밋
통과 기준:
1. 캐릭터: /home/dev/asset-packs/q-chars(Universal Base Characters)와 q-anim(Universal Animation Library)에서 한 명 + 서기·걷기·뛰기만 people 묶음으로(`npm run assets`). 속옷 차림이므로 상의·하의 색을 재질로 칠해 평상복처럼.
2. 조작: 왼쪽 엄지 가상 조이스틱(살짝=걷기, 끝까지=뛰기), 오른쪽 드래그로 카메라 회전, 두 손가락 확대·축소(범위 제한). 데스크톱은 WASD/마우스.
3. 카메라: 캐릭터 뒤 위쪽 3인칭(Big Ambitions 느낌), 부드럽게 따라옴, 건물을 뚫고 들어가지 않음.
4. 충돌: 건물·차·가로수를 통과하지 않음. 인도·도로 위 이동.
5. 건물 출입문 2m 안에 들어가면 화면 아래 "들어가기" 버튼(누르면 지금은 토스트 "곧 열려요"). 엄지로 누르기 쉬운 크기, 화면을 가리지 않게.
6. 첫 화면에서 2초 안에 조작 가능(로딩 표시). fps를 떨어뜨리지 않게(그림자·해상도 정책 유지).
7. tests/play/: Playwright로 조이스틱을 끌어 캐릭터가 움직이는지 확인하는 시나리오 하나(check.sh가 돌릴 수 있게).
8. `bash tools/check.sh --card cards/C006.md` PASS (스크린샷 포함).
