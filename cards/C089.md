# C089 광고 모듈 (Claude 클라우드 opus)
목적: 새 구상 기둥 8 — 광고를 어디에·누구에게·어떻게 할지 고르고, 효과가 들쭉날쭉(대박·무반응·역풍)하게. 순수 로직·데이터만(세션·UI 연결은 다음 카드).
고칠 파일:
- src/data/ads.ts (새: 채널·손님층·메시지·모델 데이터)
- src/sim/ads.ts (새: 캠페인 구매·결과 계산·일별 효과)
- tests/sim/ads.test.ts (새)
크기: 큼(≤400줄, 마스터 이유: 채널 8종 데이터 + 결과 모델)
내용:
- 채널 8종: flyer 전단지, banner 현수막, transit 버스·지하철, search 검색광고, sns SNS, youtuber 유튜버 협찬, tv TV, sponsor 스포츠팀 후원. 각각 주당 비용(결), 범위(동네/도시/전국 — 지금은 동네 가게라 범위가 넓으면 낭비 비율), 손님층 5종(students 학생·workers 직장인·elders 어르신·families 가족·affluent 부유층)별 적합도 0~1, 준비 기간(일), 결과 분산(작을수록 예측 가능).
  예: 전단지는 싸고 어르신·가족에 잘 먹히고 분산 작음. SNS는 학생에 강하고 분산 큼. TV는 비싸고 동네 가게엔 낭비가 큼.
- 메시지 4종(가격·품질·감성·화제성)과 광고 모델 4종(없음·동네 유명인·인플루언서·연예인). 모델이 있으면 효과가 커지지만 '모델 사고' 확률이 생긴다.
- planCampaign(입력: 채널·메시지·모델·대상 손님층·기간 주) → 예상 비용·예상 효과 범위(최소~최대)를 돌려준다(플레이어가 보는 미리보기).
- buyCampaign(ledger, buyerId, payeeId, plan, time, id) → 비용을 기존 계정 사이 이체로만 지불(새 돈 생성 금지, 같은 id 재실행은 중복 결제 안 됨, 잔액 부족은 실패).
- resolveCampaign(plan, 가게 손님층 분포, sample:number[]) → 결과: outcome('hit'|'normal'|'dud'|'backlash'), 손님층별 방문 배수(일별 감쇠 곡선, 기간 뒤 서서히 0으로), 평판 변화, 화제(입소문) 수치, 사람이 읽는 한 줄 요약(예: "버스 광고가 직장인에게 먹혔다", "모델 음주운전 기사로 불매 조짐").
  대상이 가게 실제 손님층과 안 맞으면 효과가 작아야 한다. 역풍(backlash)은 모델 사고나 화제성 메시지 과열에서만.
- adEffectOnVisit(campaigns, 손님층, day) → 그날 그 손님층 방문 배수(여러 캠페인 합산, 상한 있음).
하지 말 것: 기존 파일 수정, Math.random(샘플은 인자로), 새 npm 패키지.
통과 기준: 테스트 — 결정론(같은 입력 같은 결과), 맞는 대상 > 틀린 대상 기대 효과, 모델 없음이면 backlash 0, 10만 샘플로 채널별 hit/dud 비율이 데이터 분산과 일치, 기간 후 효과 감쇠, 결제 이체 후 전체 잔액 합 불변·중복 결제 없음. `bash tools/check.sh --card cards/C089.md --fast` PASS(Blender 없는 환경 실패만 예외).
