# C047 플레이 루프 시나리오 테스트 (테스트, Codex)
목적: C036이 화면 흐름(문 출입·결폰·아르바이트·구매·주식·저장)을 임시 스크립트로만 확인하고 지웠다. 회귀를 막기 위해 check.sh가 도는 tests/play/ 시나리오로 남긴다.
고칠 파일:
- tests/play/loop.mjs (새)
크기: 보통(≤150줄)
참고(읽기만): tests/play/walk.mjs(형식·브라우저 띄우는 법), src/ui/hud.ts(클래스 이름·버튼 문구·?phone= 쿼리), src/main.ts(cornerDiagnostics), src/game/session.ts
하지 말 것: src 변경(테스트를 위해 필요하면 멈추고 제안), 새 패키지, 커밋. 서버 브라우저가 느리니(SwiftShader 약 1fps) 대기는 넉넉히, 전체 60초 안쪽 목표.
통과 기준:
1. 시나리오: 페이지 열기 → 결폰 열기 → 일·소비 탭에서 일하기 → 상단 바 결 증가 → 결증 탭에서 1주 매수 → 결 감소·보유 1주 → 페이지 새로고침 → 시각·결·보유가 이어짐(localStorage). 문 출입은 ?phone= 장소 이동 쿼리로 대신해도 된다.
2. 실패 시 어느 단계에서 무엇을 기대했는지 메시지로 남긴다.
3. Codex 샌드박스에서는 브라우저를 못 띄울 수 있다: 그 경우 문법·논리만 맞추고 보고에 적는다(마스터가 서버에서 실행).
