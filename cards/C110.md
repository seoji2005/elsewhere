# C110 직원 위임 수정: 실제 판매 제어·급여·권한 (Claude 클라우드 opus)
목적: Codex 교차 리뷰(docs/design/REVIEW-c097.md) P1 3건·P2 3건. 통합된 main(staff 시스템 포함)에서 출발. 상세 규칙은 docs/design/R3-gpt.md B절.
1) 직원 작업이 실제 판매를 제어: 직원이 근무 중인 내 가게에서는 C087 즉시 결제 대신 구매 의도를 작업 큐에 넣고, 직원(또는 사장)의 계산 작업이 끝날 때 기존 결제를 한 번 실행. 숙련도(처리량)가 판매 수에 실제로 반영되게(시간당 상한은 작업 처리량으로 대체).
2) 채용 당일 급여: 실제 유급 근무 분을 기존 고용 기록에 연결해 누적 정산(R3 B13 공식). 지각한 분은 무급.
3) 승인 한도: 공급처·보충 판단 ID별 총액으로 검사(품목 쪼개기 우회 금지).
4) 정책 수정 뒤 열린 요청: 자동 처리되면 요청 해소, 승인 시 부족 수량·견적 재검증.
5) 임금 체불 판단: 직원별 미지급 임금만(임대료 체납 제외), 퇴사 예고 표시·원인 해결(임금 지급) 경로.
6) 예약 정책: M1 최소 — 큰손 대량 예약(C095 basket 큰손)이 있으면 예약 재고 보호와 '약속 시각 우선' 작업 선택에 반영. 예약 변경은 요청으로.

크기: 큼(≤400줄)
하지 말 것: 기존 테스트 기준 완화, 돈 생성, C087 혼자 운영 밸런스 악화(혼자 운영 첫 주 기준 유지 — 전후 표), 다른 시스템 변경.
통과 기준: 각 항목 테스트 + 숙련 12시간 직원의 하루 판매 수 > 신입(표) + `bash tools/check.sh --card cards/C110.md --fast` PASS.
