# C076 결폰 메신저 (M2-02, Claude 클라우드 opus)
목적: features.json M2-02. 떨어져 있을 때 결폰 메신저로 주민과 짧게 대화하고, 그 결과가 관계·약속(소개팅·약속 기능)에 반영된다. 관계 단계에 따라 답장 말투·속도가 다르다.
먼저 읽기: AGENTS.md, src/ui/hud.ts·hud.css(결폰 탭 구조), src/ui/talk.ts, src/game/session.ts, src/sim/dialogue.ts·bonds.ts·matchmaking.ts, tests/play/social.mjs.
고칠 파일:
- src/sim/messenger.ts (새: 대화 상태·답장 규칙)
- src/game/session.ts (메신저 행동 노출, 저장 기본값)
- src/ui/hud.ts, src/ui/hud.css (결폰에 메신저 탭)
- tests/game/messenger.test.ts (새), tests/play/messenger.mjs (새)
크기: 큼(≤400줄, 마스터 이유: 로직·화면·플레이 시나리오를 한 기능으로)
하지 말 것: 기존 탭·대화 화면 동작 변경, 판타지 장식, 새 npm 패키지, 저장 호환 깨기, 기존 테스트 수정.
통과 기준: 폰 가로 화면에서 결폰 → 메신저 → 주민 선택 → 메시지 보내기 → 답장(관계 단계별 말투) → 약속 잡기가 실제 약속 목록에 생김(플레이 시나리오), 하루 연락 횟수 상한, 상대가 잘 때는 다음 아침 답장. 스크린샷 2장(.shots). `bash tools/check.sh --card cards/C076.md` PASS(Blender 없는 환경의 tests/tools/normalize 실패만 예외).
