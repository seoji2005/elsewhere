# C086 결폰 '내 가게' 탭 + 날씨·평판 표시 (Claude 클라우드 opus)
목적: C085 경영 로직을 폰 화면에서 쓰게 한다(타이쿤 핵심 루프). session의 rentStore, openShop, orderStock, setShopPrice, offerJob, fireEmployee, shopReport를 연결.
화면(가로 폰, 결폰 안 새 탭 '내 가게'):
- 가게가 없을 때: 빈 점포 목록(장소·보증금·하루 임대료·가능 업종) → 계약 → 업종 선택 → 개업.
- 가게가 있을 때: 오늘 요약(매출·순이익·방문·불만·평판·날씨) / 재고(품목별 수량·원가·판매가 ±버튼·주문 버튼, 입고 예정 표시) / 직원(현재 직원·시급·근무 시간, 해고) / 7일 결산 간단한 막대.
- 직원 구하기: 아는 주민 목록 → 일자리 제안 → 수락/거절 이유 대사(관계와 연결된 문장).
- 상단 바에 날씨 아이콘 한 글자(맑음·흐림·비)와 연체 경고 표시.
고칠 파일:
- src/ui/hud.ts, src/ui/hud.css
- src/ui/shop.ts (새: 내 가게 탭 렌더 — hud.ts가 너무 커지지 않게)
- tests/play/shop.mjs (새: 임대→개업→주문→가격 조정→다음 날 결산 확인→직원 제안)
크기: 큼(≤400줄, 마스터 이유: 탭 하나에 경영 화면 전체)
하지 말 것: sim·session 로직 변경(필요하면 보고), 기존 탭 동작 변경, 판타지 장식, 새 npm 패키지.
통과 기준: 폰 가로 스크린샷 3장(.shots-c086/ jpg 커밋: 빈 점포·운영 요약·직원 제안)을 직접 보고 글자 잘림·겹침 없음, 버튼 손가락 크기(44px 이상), 플레이 시나리오 통과, `bash tools/check.sh --card cards/C086.md` PASS(Blender 없는 환경 실패만 예외).
