# C115 가게가 보이게: 손님이 걸어와 줄 서고, 사장이 직접 계산 (Claude 클라우드 opus)
목적: QA 1·2번(가장 중요) + GDD 원칙 7. 리테일 타이쿤의 손맛: 손님이 실제로 가게 앞에 와서 줄을 서고, 머리 위에 한마디가 뜨고, 직원이 없을 때는 사장이 '계산' 버튼을 눌러 판다.
- 손님 보이기: 기존 거리 주민 표시(cast, C083 생활 동작 — 걷기·서기·구매 클립)를 써서, 내 가게 방문 중(대기열 waiting)인 주민을 가게 문 앞에 줄 세워 보여 준다(최대 4명, 그 이상은 '+n'). 새 모델·그래픽 제작 금지(그래픽 동결) — 있는 아바타·클립만.
- 말풍선을 손님 머리 위에(화면 좌표 투영), 왼쪽 위 목록은 보조.
- 직접 계산: 사장이 가게에 있고 직원이 근무 중이 아니면, 줄 맨 앞 손님에 '계산' 큰 버튼(엄지 영역, 44px+) → 기존 결제(한 번) → '띵'·한마디. 누르지 않으면 손님 인내가 줄고 떠남(기존 규칙). 흥정 손님이면 버튼 두 개(깎아 주기/정가).
- '가게 들어가기'는 가게 안 대신 가게 앞 계산대 시점(카메라만 가게 앞으로)으로 — 주민 목록이 열리지 않게.

- src/ui/hud.css

크기: 큼(≤400줄)
하지 말 것: 새 3D 에셋·그래픽 스타일 변경, 경제 숫자 변경, C112·C113 파일 영역(문구·공연) 건드리기, 돈 생성.
통과 기준: 직원 없을 때 사장 계산으로만 판매(테스트), 계산 안 하면 인내 초과로 떠남, 흥정 두 버튼, 폰 가로 스크린샷 3장(.shots-c115/: 줄 선 손님과 머리 위 말풍선, 계산 버튼, 흥정)을 직접 보고 겹침 없음, 아이폰 성능 고려(손님 4명 이하 표시), `bash tools/check.sh --card cards/C115.md` 전체 PASS.
