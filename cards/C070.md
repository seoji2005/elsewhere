# C070 빌드 용량 확보 (Codex, high)
목적: features 전반(캐릭터·도시)의 바탕. 단일 html 상한 10240KB 안에 C063 리세(lisec.vrm ≈ +990KB)와 C067 건물 키트(+390KB)를 함께 넣을 자리 ≥ 900KB를 만든다. 지금 main 빌드 ≈ 9360KB.
조사 먼저(보고 맨 위에 표): src/assets/*.glb·*.vrm 각각 무엇이 용량을 차지하는지(메시·모프·텍스처·애니메이션), 어떤 코드가 무엇을 쓰는지. 큰 후보: people.glb 735KB(anime 모드는 애니메이션 클립만 씀 — avatar.ts `loadAssets('people')`; style=current의 character.ts는 메시도 씀), city.glb 2.2MB, 각 VRM의 표정 모프·텍스처.
고칠 파일: tools/assets.mjs, assets/manifest.json, src/render/assets.ts, src/anime/avatar.ts, src/player/character.ts, src/assets/*.glb(재생성만), src/assets/*.vrm(재생성만)
크기: 보통(≤150줄)
하지 말 것: 화면에 보이는 품질 저하(텍스처 해상도 낮추기, 표정·모션 삭제, 건물 삭제), style=anime 기본 화면 변화, sim·ui 변경, 새 npm 패키지, 용량 상한 숫자 변경, 테스트 수정, 커밋.
방향 예: 모션 전용 번들 분리(메시 없는 클립만, anime 모드는 그것만 로드), 중복·미사용 노드/텍스처 제거, 더 촘촘한 양자화. 판단이 갈리면 고치지 말고 보고의 "제안"에.
통과 기준: npm run build:single 크기가 지금보다 ≥ 900KB 작음(보고에 전/후 숫자), 기본 화면·style=current·cast=1 스크린샷이 전과 같아 보임(tools/shot.mjs), `bash tools/check.sh --card cards/C070.md` PASS(session 180일 테스트 시간 초과는 서버 부하 환경 문제 — 그 경우 단독 재실행 결과를 적는다).
