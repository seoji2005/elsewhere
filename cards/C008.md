# C008 가상 회사 주식 (시뮬레이션만)

목적: M1-15. 가상 회사 3개, 주가가 세계 사건·NPC 사업에 반응, 사고팔기. 화면은 만들지 않는다.
고칠 파일:
- src/sim/market.ts, src/data/companies.ts
- tests/sim/market.test.ts
크기: 보통(≤150줄)
하지 말 것: 렌더·UI, 기존 sim 파일 수정(필요하면 제안), 새 패키지, 커밋
통과 기준:
1. companies.ts: 이 세계만의 회사 3개(C005의 장소·NPC 이름과 어울리게: src/data/*.ts 읽기만). 업종·기본 가격·변동성.
2. market.ts: 시드 고정 난수로 결정적인 하루 단위 가격 변화 + 사건 충격(applyEvent: 회사·크기·지속일) + NPC 사업 연결 훅(매출 증감 → 가격 영향).
3. 매수·매도는 C004 ledger.transfer로만 돈이 움직이고, 보유 수량은 음수 불가. 수수료 1%.
4. 테스트: 결정성, 사건 후 가격 이동, 잔액 부족 매수 실패, 보유 초과 매도 실패. `bash tools/check.sh --fast --card cards/C008.md` PASS.
