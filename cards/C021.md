# C021 NPC 생성기 (시뮬레이션·데이터)
목적: M1-17. 정해진 연애 상대 없이 아주 많은 NPC. 성격 유형·말투·외형 변수·직업·일과를 조합해 새 게임마다 다른 사람들을 만든다(시드 고정 = 결정적).
고칠 파일:
- src/sim/npcgen.ts, src/data/archetypes.ts, src/data/names.ts
- tests/sim/npcgen.test.ts
크기: 큼(≤400줄)
참고(읽기만): src/data/npcs.ts(손으로 만든 핵심 NPC 6명 — 생성 NPC와 같은 타입), src/data/places.ts, src/sim/npc.ts·relationship.ts·dialogue.ts(공개 타입·함수), /home/dev/research/R011/report.md(말투 규칙 예), R008/report.md(많은 인원을 가볍게).
하지 말 것: 기존 파일 수정(필요하면 제안), 화면, 새 패키지, 커밋
통과 기준:
1. archetypes.ts: 성격 유형 10개 이상(예: 차분한 공적/사적 반전형, 다정한 수다형, 무뚝뚝한 장인형 …), 유형마다 말투 규칙(존댓말·반말 전환 조건, 어미, 호칭, 문장 길이)과 좋아하는 것/싫어하는 것 경향.
2. names.ts: 이 세계만의 이름 음절 규칙(기존 이름 아로·누엘·소리안·벨로·이리·리세와 어울리게) — 실제 인물 이름 피하기.
3. npcgen.ts: generate(seed, count) → 핵심 NPC와 같은 타입의 NPC들. 직업·일과는 장소 수용량을 넘지 않게, 외형 변수(머리 길이·색·체형·옷 색 계열 등 숫자/열거값, 나중에 화면이 씀).
4. 50명 생성이 폰에서 가볍다(생성 50ms 이내 목표, 테스트로 측정). 같은 시드 = 같은 결과.
5. `bash tools/check.sh --fast --card cards/C021.md` PASS.
