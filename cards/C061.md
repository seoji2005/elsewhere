# C061 리세를 Blender 코드로 처음부터 만들기 — 1단계 (화면, Claude 작업자 fable)
목적: 사용자(2026-10-15): "블렌더로 처음부터 제작해봐." VRoid 샘플의 얼굴·헤어·옷 실루엣 한계를 넘기 위해, 서버 Blender 4.2(헤드리스, /usr/local/bin/blender, GPU 없음)와 VRM Add-on 4.10(MIT, dev 계정에 설치됨, bpy.ops.export_scene.vrm)으로 리세를 코드로 모델링해 VRM으로 내보내고 게임에서 VRoid판과 비교한다.
설정·외형(읽기만): /home/dev/research/R011/report.md(리세), R010(오데트와 다르게 — 고유 요소 3개 이상 바꿈), DIRECTION.md(SD 2.7등신, 현대 생활복: 조율사 작업복+코트, 판타지·무기 금지, 툰은 fable A: 하드 셀·평면색·외곽선), C057 리세 시제품 팔레트(src/anime/lise.ts가 cl/c057 브랜치에 있음: 짙은 회청 단발 보브, 회청→호박 홍채, 회청 작업조끼+플리츠, 호박색 타이, 반쯤 감은 눈+작은 미소).
렌더링 참고: R016a·R016b(얼굴 SDF·램프 규격), tools/face-sdf.mjs.
고칠 파일:
- tools/blender/*.py (새: 모델링·리그·표정·내보내기 스크립트, 재실행하면 같은 결과)
- src/assets/lise-b.vrm (새, 1.5MB 이하)
- src/anime/*.ts (VRM 하나를 ?model=lise-b 로 불러오기 — 최소)
- src/main.ts (쿼리 연결 몇 줄), assets/manifest.json (필요할 때만)
크기: 큼(≤400줄. 마스터 이유: 첫 캐릭터의 모델링·리그·표정·내보내기 파이프라인을 한 번에 세워야 판단 가능. 넘치면 멈추고 남은 부분을 보고)
하지 말 것: VRoid 메시 재사용(이번엔 처음부터. 얼굴 눈·입 텍스처는 코드로 그린 그림), sim·ui·scene 변경, 새 npm 패키지(Blender 안 파이썬 표준·bpy·bmesh만), 커밋, 원신 자산.
통과 기준 (1단계):
1. 형태: SD 2.7등신 몸(부드러운 저폴리 + 서브디비전 적용 후 1인 3만 삼각형 이하), 둥근 애니 얼굴(큰 눈 위치, 작은 코·입), 단발 보브 머리(몇 개의 볼륨 덩어리/카드), 작업 조끼+플리츠 스커트+짧은 코트 실루엣, 신발. 평면 색 재질(툰 A와 어울리게).
2. 리그: VRM 휴머노이드 필수 뼈(hips~손발·머리·눈) 자동 가중치, 걷기·서기 리타깃이 게임에서 동작. 머리카락·코트 끝에 스프링 본 몇 개.
3. 표정: blink(양쪽), happy(작은 미소), 입 a 최소 3개 — 셰이프 키 또는 눈·입 텍스처 교체.
4. 게임: `?model=lise-b`(+ `&close=1` 클로즈업이 있으면 활용)로 서고 걷고 깜빡인다. MToon 툰 + 외곽선.
5. 확인: Blender Cycles CPU(저샘플)로 정면·3/4 렌더 PNG, 그리고 `~/ops/bin/gha-shots <워크트리> "model=lise-b" "model=lise-b&cast=1&dist=3.5&pitch=0.12"` — 직접 보고 고친다(최대 5회). 서버 `bash tools/check.sh --card cards/C061.md` PASS.
