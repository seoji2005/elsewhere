# C065 STYLE 기반 1: 시간대 3종·장소 프리셋·선과 음영 통일·검사 시트 (화면, Claude 작업자 opus)
목적: docs/look/STYLE.md(아트 바이블, 반드시 먼저 읽기)가 정한 첫 카드. 세계 어디서 찍어도 같은 그림체가 되도록 공통 렌더 규칙을 코드에 넣고, 통일감 검사(§9)를 할 수 있는 도구를 만든다. 동네 자체(뉴욕풍 건물·간판·소품)는 다음 카드.
고칠 파일:
- src/main.ts, src/render/*.ts, src/scene/looks.ts, src/player/player.ts, src/ui/talk.ts(대화 구도만)
- src/anime/avatar.ts, src/anime/wardrobe.ts (캐릭터 선·그늘을 STYLE과 같게)
- tools/style-sheet.mjs (새: GHA 결과 샷들을 접촉 시트 1장으로 + 참고 5장 나란히, §9 자동 검사 3·6번 수치)
크기: 큼(≤400줄. 마스터 이유: 모든 화면의 공통 규칙과 검사 도구를 한 번에)
하지 말 것: sim·game·ui(talk 제외) 변경, 새 npm 패키지, 실제 브랜드, 커밋. 기존 쿼리 유지.
통과 기준:
1. `?time=day|dusk|night`: §2 팔레트(하늘 위·띠·아래, 햇빛·채움광, 그늘 곱, 선 잉크). 밤은 달빛+발광(창·가로등)만, 블룸은 발광체만.
2. `?spot=A..E`: 지금 동네 안에서 §7 구도(S1~S5)에 가장 가까운 카메라 프리셋 5개(장소가 아직 없으면 지금 코너에서 비슷한 높이·각도로; 보고에 어느 것이 임시인지).
3. 선: §3 표대로 캐릭터·환경 같은 굵기·색(ToonEdges dpr 보정, strength 약 0.75, 잉크색 혼합), 순검정 없음. 음영 2단, 캐릭터 MToon 그늘 곱도 §2와 같게.
4. 카메라 기본값 §7(거리 걷기 FOV 38·거리 7m·피치 14° 등), 대화 클로즈업이 6.5~7등신에서 머리가 잘리지 않게.
5. tools/style-sheet.mjs: `~/ops/bin/gha-shots` 결과 폴더를 받아 4열 접촉 시트 PNG + 참고 5장 + 자동 검사(순검정 비율, 하늘 패치 ΔE) 출력.
6. 검사: gha-shots로 spot A~E × day/dusk/night 15장 + 대화 1장 → 시트 → §9 13칸 표(자동 2칸 + 눈으로 본 나머지, 아직 안 되는 칸은 다음 카드로 표시). 최대 3라운드 직접 보고 고친다. 서버 `bash tools/check.sh --card cards/C065.md` PASS.
