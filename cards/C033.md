# C033 확실한 툰: 제미나이 그래픽 안 + 툰 2안 비교 (화면, Codex astra 초안 → 마스터 평가 → 필요하면 fable 마감)
목적: M1-04·M1-19. 사용자(2026-10-15): "툰스럽게 갈 거면 확실하게, 지금은 어정쩡하다." 원인(마스터): 캐릭터는 MToon 셀 음영+외곽선인데 도시는 매끈한 조명·외곽선 없음·사실적 벽돌/창 텍스처, 에셋 팩 질감도 섞여 있다. cards/MASTER_FEEDBACK.md 2장(제미나이) 안을 바탕으로 깔고, 그 위에 툰 강도 2안을 `?toon=a|b`로 바꿔 볼 수 있게 한다(사용자가 고르거나 둘 다 반려).
공통(두 안 모두, MASTER_FEEDBACK 2장 ①③④⑤ — 5장 참조 코드 참고 가능):
- FOV 가로 38 / 세로 54, 카메라 거리 조정. 그림자 반경 22m + 플레이어 추적 텍셀 스냅. 배경 건물 material.clone() 제거 → 정점 seed로 색 변주(드로우콜 감소). 빛씨 부유 입자(T.Points, 1 draw). VRM frustumCulled 복구(고정 bounding sphere). 찻방 건물 간판 "서점"을 장소에 맞게(잔물결 찻방).
A안 "셀 애니 배경" (`?toon=a`, 기본):
- 배경 재질 전부 2단 하드 셀 음영(NearestFilter 램프, 빛/그림자 경계가 딱 끊김), 그림자색은 라벤더(0.78,0.82,1.04 계열)로 색을 입힘, 경계에 얇은 난색 띠.
- 건물·소품·나무·차에 외곽선(정적 병합 메시에 inverted hull 또는 화면공간 깊이/법선 엣지 — 폰 비용 보고 고른다). 선 색은 검정이 아닌 각 재질을 어둡게 한 색. 캐릭터 외곽선과 굵기 맞춤.
- 사실적 텍스처(벽돌·창 사진풍 맵)는 평면 색 + 단순한 선 패턴(벽돌 줄눈 몇 줄, 창틀)으로 바꿈. 창문 내부는 제미나이 패럴랙스 대신 단순한 발광 색면 2톤.
B안 "부드러운 일러스트 툰" (`?toon=b`):
- MASTER_FEEDBACK 2장 ② 그대로: 3단 부드러운 램프 + 라벤더 음영 + 살구빛 경계 띠 + 상단 림, 창문 3D 패럴랙스, 구형 나뭇잎 법선. 외곽선은 캐릭터만.
