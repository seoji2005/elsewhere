# C033 세션을 화면에 연결: 시각·돈 표시, 자동 저장 (Codex)
목적: M1-16 화면 쪽. sim·세션(src/game/session.ts)은 다 있지만 화면과 연결되지 않았다. 게임을 열면 세션이 이어지고, 시간이 흐르고, 화면 위쪽에 게임 시각과 내 돈이 보이며, 닫았다 열어도 이어진다.
고칠 파일:
- src/main.ts (세션 생성·tick·저장 연결, 몇 줄만)
- src/ui/hud.ts, src/ui/hud.css (상단 정보 줄)
- src/ui/clock.ts (새, 필요하면 — 시각·돈 문자열 만들기)
- tests/play/session.mjs (새, 플레이 시나리오)
크기: 보통(≤150줄)
참고(읽기만): src/game/session.ts(createSession·tick·saveNow·state), storage.ts(localStorageAdapter), src/sim/clock.ts(gameTime), purse.ts(funds), tests/play/walk.mjs(시나리오 형식)
하지 말 것: sim·game 파일 수정(필요하면 제안), src/anime·src/player 변경(그래픽 작업 브랜치와 겹침), 새 패키지, 커밋. 꾸미기는 최소(작은 반투명 띠 하나, 폰 가로 화면에서 조이스틱·버튼과 겹치지 않게).
통과 기준:
1. main.ts: 시작 때 createSession(localStorageAdapter()), 매 프레임 session.tick(dt), 플레이어 위치·방향을 session.state.player에 반영, 시작 때 저장된 위치로 플레이어를 놓는다. visibilitychange(hidden)·pagehide에 saveNow().
2. 상단 띠: "N일차 HH:MM · ₩금액"(플레이어 지갑). 1초에 몇 번만 갱신(매 프레임 DOM 쓰기 금지).
3. 저장 실패·손상본 복구 시 토스트 한 줄("저장을 못 했어요" / "이전 저장을 백업하고 새로 시작했어요").
4. tests/play/session.mjs: 브라우저로 열기 → 몇 초 진행 → 표시된 시각이 흐름 → 새로고침 → 시각이 처음으로 돌아가지 않고 이어짐.
5. `bash tools/check.sh --card cards/C033.md` PASS(전체 검사, 서버 브라우저는 느리니 시나리오는 짧게).
