# C091 타이쿤 공통 기반: 결정론 난수·묶음 지급·명령 ID (Claude 클라우드 opus)
목적: 새 구상 모든 타이쿤 모듈(광고·전문가·라이벌·기회·사건)이 함께 쓸 기반. GPT 기획자 P01 제안(2026-10-16 설계 R1).
고칠 파일:
- src/sim/tycoonCore.ts (새)
- tests/sim/tycoon-core.test.ts (새)
크기: 보통(≤150줄; 테스트 포함 큼≤400 허용)
내용:
1. 결정론 난수: roll(seed, system, entityId, index) → [0,1) 실수. 문자열 해시(FNV-1a 32 등) + 섞기 함수(mulberry32/splitmix). UI 열기·배열 순서·틱 크기와 무관하게 같은 입력이면 같은 값. pick(list, r), weighted(entries, r), between(min,max,r) 헬퍼.
2. 묶음 지급 settle(ledger, batchId, legs: {from,to,amount,reason}[], time) → 모든 다리를 먼저 검증(계정 존재·금액 자연수·순 잔액 충분 — 같은 계정의 여러 출금 합산)하고 전부 성공할 때만 기존 transfer로 한 번에 반영. 하나라도 실패면 아무것도 바뀌지 않는다. 다리 id = `${batchId}:${i}`. 같은 batchId 재실행은 중복(무변화)으로 성공, 같은 batchId에 다른 내용(금액·계정)이면 거부(첫 다리의 기존 거래와 비교, compactLedger 이후에도 최소한 중복 판정은 유지).
3. 명령 순번: nextId(state: {seq:number}, kind) → `${kind}:${seq}` 후 seq+1(저장 가능한 순번, Math.random 금지).
하지 말 것: 기존 파일 수정(ledger.ts 포함), 새 npm 패키지.
통과 기준: 테스트 — roll 결정론·분포 대략 균일(10만 샘플 10구간 각 ±1%p), 입력 하나만 바뀌어도 값이 다름, settle 원자성(중간 다리 잔액 부족 → 전체 무변화), 재실행 중복 처리, 내용 다른 재실행 거부, 총액 보존. `bash tools/check.sh --card cards/C091.md --fast` PASS(Blender 없는 환경 실패만 예외).
