# C090 전문가 고용 모듈: 회계사·변호사 (Claude 클라우드 opus)
목적: 새 구상 기둥 7 — 회계사(세금·실수·세무조사·드물게 횡령)와 변호사(계약서의 숨은 조항 발견)를 고용하는 의미가 있게. 순수 로직·데이터만(세션·UI 연결은 다음 카드).
고칠 파일:
- src/data/advisors.ts (새: 직종·등급·수수료·대사)
- src/sim/advisors.ts (새)
- tests/sim/advisors.test.ts (새)
크기: 큼(≤400줄, 마스터 이유: 직종 2개의 규칙 + 계약 조항 데이터)
내용:
- 직종 5종 데이터(accountant 회계사·lawyer 변호사·labor 노무사·pr 홍보·consultant 컨설턴트), 이번 카드 규칙은 회계사·변호사만. 등급 3단계(싸고 실수 잦음 / 보통 / 비싸고 믿을 만함): 주급(결), 실수율, 근속 주수에 따른 충성도(실수율 감소).
- 회계사: weeklyTax(이번 주 이익, 회계사 상태, sample) → 세금(절감률은 등급별), 실수면 신고 오류 표시 → auditRisk 누적. audit(sample) → 추징금(벌금 포함). 횡령: 1등급만 아주 드물게(주당 0.5% 안팎), 충성도 높으면 더 낮음. 횡령·세금·수수료는 모두 기존 계정 이체로(세금은 시청 계정 'city' 같은 기존/주어진 계정, 새 돈 생성 금지).
- 변호사: 계약서 생성 generateContract(kind: 임대·납품·고용·광고, seed) → 겉 조건 + 숨은 조항 0~3개(자동 갱신, 과한 위약금, 독점 공급, 일방 가격 인상, 손해 책임 전가 등 8종 이상, 각 조항의 게임 효과 값). reviewContract(contract, 변호사 등급|null, sample) → 발견한 조항 목록(등급별 발견 확률, 변호사 없으면 아무것도 못 봄)과 협상으로 뺄 수 있는지. 플레이어가 보는 문장(예: "제7조: 3개월 전 통지 없으면 1년 자동 연장 — 빼 달라고 할까요?").
- 전문가 한마디 대사: 직종×등급×상황(고용·세금 보고·실수·조항 발견·없음) 1~2줄씩, 현대 한국어, 판타지 단어 금지, 통화 '결'.
하지 말 것: 기존 파일 수정, Math.random, 새 npm 패키지.
통과 기준: 테스트 — 결정론, 등급이 높을수록 실수율·숨은 조항 놓침 확률이 낮음(10만 샘플), 변호사 없으면 발견 0, 근속이 길면 실수율 감소, 횡령은 1등급에서만 발생, 모든 이체 후 전체 잔액 합 불변. `bash tools/check.sh --card cards/C090.md --fast` PASS(Blender 없는 환경 실패만 예외).
