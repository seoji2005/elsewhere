# C095 손님 개성 연결 + 수요 훅 (Claude 클라우드 opus)
목적: docs/design/GDD.md §5. C088 손님 개성(src/sim/persona.ts)을 실제 내 가게 손님에 연결해 리테일 타이쿤처럼 "손님이 한마디씩" 하게 하고, 이후 광고·라이벌·사건 시스템이 손님 방문에 끼어들 '수요 훅'을 만든다.
고칠 파일:
- src/game/tycoon/system.ts — TycoonSystem에 선택 훅 2개 추가: `visitBonus?(ctx, s, v: { npcId, businessId, hour }): number`(방문 확률 가산 %p, 여러 시스템 합산·상한 +40) / `onShopEvent?(ctx, s, e: ShopEvent)`(내 가게 방문 결과: purchased·불만 이유·haggle·parkingFull 등).
- src/game/tycoon/patrons.ts (새 시스템 'patrons') — 주민별 개성 배정(assignPersona + ctx.roll, 저장), 내 가게 방문 횟수(3회 이상 단골 승격 promotePersona), 주차 칸 2개(주차 빌런이 20분 점유, 차로 오는 유형 — 큰손·바쁜 직장인 일부 — 은 칸이 없으면 지나감 + parkingFull 한마디), 흥정꾼 haggle(플레이어가 가게에 있으면 '깎아 줄까요?' 요청을 대기열에 남기고 명령 answerHaggle(accept)로 처리, 없으면 expensive로), 큰손 basket(재고가 있으면 여러 개 구매 — 기존 visitStore/checkout을 품목 수만큼 별도 visitId로), 한마디 피드(최근 30줄: { minute, npcId, name, personaId, situation, text }, 같은 줄 하루 1회).
- src/game/tycoon/registry.ts — patrons 등록 한 줄.
- src/game/session.ts — 내 가게 손님 처리 지점에서만: 방문 확률에 Σ visitBonus 더하기, applyPersona/decideWithPersona 적용, 결과마다 onShopEvent 호출. 주민 소유 가게 동작은 그대로.
- src/ui/shop.ts, src/ui/hud.ts, src/ui/hud.css — 플레이어가 내 가게 안에 있으면 손님 한마디를 말풍선 토스트로(2초, 겹치면 줄 세움), 흥정 요청은 [깎아 주기]/[안 돼요] 버튼. 내 가게 탭에 "오늘 손님 한마디" 최근 5줄.
- tests/game/patrons.test.ts (새)
- tests/game/session.test.ts — 마스터 승인: 첫 시스템 등록으로 세이브 v6, version toBe(5) 두 줄을 6으로.
- tests/game/tycoon-registry.test.ts — 기준 갱신(작업자 가정): 기본 등록부가 비어 있다고 가정한 v5 테스트 두 줄에 빈 등록부 [] 명시.
크기: 큼(≤400줄, 마스터 이유: 세션 연결 + 시스템 + UI)
하지 말 것: persona.ts·data/personas.ts 수정(필요하면 보고), C087 밸런스 숫자 변경, 기존 테스트 수정, 돈 생성, Math.random.
통과 기준(테스트): 같은 시드 같은 배정·대사, 3회 방문 뒤 단골, 주차 빌런 점유 중 차 손님 감소, haggle 수락 시 정확히 할인가 이체·거절 시 판매 없음, visitBonus 테스트 시스템(+40)이 방문 수를 늘림, 30일 C087 밸런스 테스트 그대로 통과, 총액 보존, 틱 분할 동일. 폰 가로 스크린샷 2장(.shots-c095/: 말풍선, 흥정 버튼)을 직접 보고 겹침·잘림 없음. `bash tools/check.sh --card cards/C095.md --fast` PASS(Blender·180일 시간 초과 환경 예외).
