# C101 전문가 계약 검토 연결 (Claude 클라우드 opus)
목적: docs/design/GDD.md §2 전문가. C090(src/sim/advisors.ts)을 실제 게임에 연결: 계약 원문은 처음부터 읽을 수 있고, 변호사는 조항의 의미·위험·수정안을 설명한다. 첫 대상은 가게 임대 계약(rentStore) — 건물주 소리.
고칠 파일:
- src/game/tycoon/counsel.ts (새 시스템 'counsel') — 아는 전문가 목록(주민 중 2명을 변호사·회계사로 배정: 등급 1·2, 시드 고정), 계약 초안 생성(advisors.generateContract('임대', seed) — 임대 기간·숨은 조항 0~3개는 계약 생성 때 확정, 원문 전체를 조항 번호와 함께 저장), 명령 `requestReview(contractId, advisorId)`(수수료 1회 settle, 등급별 검토 일수 뒤 결과 메시지 — 같은 계약·같은 전문가 재검토는 같은 결과(재굴림 금지)), `negotiate(contractId, clauseArticle)`(협상 가능 조항이면 제거·대가로 하루 임대료 +1 등), `sign(contractId)` → 기존 rentStore 호출 + 남은 조항 효과를 계약 상태로 보존(효과 발동은 지금은 자동 갱신·위약금 두 가지만: 임대 종료 시 위약금 이체).
- src/game/tycoon/registry.ts — counsel 등록 한 줄.
- src/ui/shop.ts, src/ui/hud.ts — 빈 점포 계약 화면: 조항 목록(원문 전부, 짧은 한 줄씩), [변호사에게 맡기기(수수료·기간)], 검토 결과는 조항 옆에 '위험'·'수정안' 표시, [이 조항 빼 달라고 하기], [서명]. 검토 중이면 "n일 뒤 결과" 표시.
- src/game/session.ts — rentStore 경로가 counsel 계약을 거치도록 한 군데만(기존 rentStore 직접 호출 테스트는 그대로 동작).
- tests/game/counsel.test.ts (새)
크기: 큼(≤400줄)
하지 말 것: advisors.ts·data/advisors.ts 수정(필요하면 보고), 기존 임대 숫자·테스트 변경, 돈 생성.
통과 기준(테스트): 원문 조항은 검토 전후 동일, 같은 계약 재검토 결과 동일, 수수료 1회, 변호사 없이 서명해도 조항 원문은 보임(의미 설명만 없음), 협상으로 뺀 조항은 효과 없음, 남은 위약금 조항이 임대 종료 때 이체, 저장 복원, 총액 보존. 폰 가로 스크린샷 2장(.shots-c101/) 직접 확인. `bash tools/check.sh --card cards/C101.md --fast` PASS(Blender·180일 시간 초과 환경 예외).
