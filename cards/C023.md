# C023 SD 비율 + 현대 생활복 캐릭터 시제품 — 그림체 판단용 (Codex astra 초안 → 마스터 품질 평가 → 필요하면 fable 마감)

목적: M1-19. 사용자가 폰에서 "이 방향 좋다"를 판단할 수 있게, C015 VRM 캐릭터를 SD(귀여운) 비율로 바꾸고 현대 생활복을 입힌 사람 여러 명을 한 화면에 세운다.
배경: 사용자 결정(DIRECTION.md 그림체·캐릭터 기준) — 애니메이션풍 + SD 비율, 의상은 현대 가상 사회의 생활복(직업·성격이 드러나게, 판타지 장식·무기 금지). NPC를 아주 많이 둘 것이라 "적은 원본으로 많은 사람"이 되는지가 핵심.
재료: /home/dev/asset-packs/vroid-cc0/ — AvatarSample_F(원피스), Sendagaya Shino(Tops·Bottoms·Accessory·Shoes 재질이 따로, 현대복). 둘 다 VRoid 기본 몸(같은 뼈 이름·UV 배치), 라이선스 수정·재배포 허용(LICENSE-NOTE.txt).
  추가 원본은 리서치 R012(/home/dev/research/R012/report.md, 진행 중)가 끝나면 마스터가 알려 준다. 이 카드는 위 둘로 끝낼 수 있게 만든다.
고칠 파일:
- src/anime/*.ts (새 파일 포함)
- src/main.ts
- assets/manifest.json, src/assets/* (Shino 줄인 vrm), tools/assets.mjs (필요할 때만)
크기: 큼(≤400줄. 마스터 이유: 비율·의상·줄 세우기 세 가지를 한 번에 봐야 판단이 된다)
하지 말 것: sim·데이터·UI 변경, 새 패키지, 커밋. 기존 `?style=current`, `?time=`, `?debug=1`은 그대로 동작해야 한다. 판타지 장식·무기.
통과 기준:
1. SD 비율: 런타임 뼈 비율 조정으로 `?sd=0|1|2`(0 원래, 1 약 4~4.5등신, 2 약 3등신; 기본은 작업자가 더 낫다고 본 쪽). 머리카락·치마 스프링 본, 눈 깜빡임·시선, 걷기·뛰기(리타깃)가 깨지지 않는다(발이 땅에 닿고 미끄러짐이 심해지지 않음, 손이 몸을 뚫지 않음 정도).
2. 현대 생활복: 재질별 색·무늬 바꾸기(캔버스로 텍스처 다시 칠하기 또는 색 곱하기)와, 같은 VRoid 몸이니 가능하면 부품 섞기(예: Shino 상·하의 + F 머리·얼굴). 머리색·눈색·피부톤도 바뀐다. 직업·성격이 드러나는 옷차림 5벌 이상(예: 조율사 작업복 톤, 카페 점원 앞치마 색, 사무직 단정한 무채색, 학생 캐주얼, 화사한 사교형). 원본 실루엣 한계(코트 같은 새 옷 모양 불가 등)는 보고에 적는다.
3. 줄 세우기: `?cast=1`이면 주인공 옆 거리에 서로 다른 사람 5명 이상이 서 있다(서기 동작·깜빡임, 카메라 쪽 시선). 주인공은 지금처럼 조이스틱으로 움직인다. `?cast=1&sd=0`과 `?cast=1&sd=2` 같은 시점 비교 가능.
4. 성능: 6명 기준 그리기 호출·삼각형을 보고. 폰 60fps를 해치지 않게(재질·텍스처 공유, 같은 원본은 한 번만 불러오기·복제). 빌드 10240KB 이하.
5. 스크린샷: Codex는 네트워크가 없으니 GitHub Actions 스크린샷은 마스터가 찍는다(`cast=1`, `cast=1&sd=0`, `cast=1&sd=2`, `cast=1&dist=3.5&pitch=0.25`). 서버 `bash tools/check.sh --card cards/C023.md` 최종 PASS.
