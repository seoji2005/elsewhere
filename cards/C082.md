# C082 자산 수입 파이프라인: Tripo → Blender 자동 정리 → 미리보기 (GitHub Actions, Codex sol high)
목적: DIRECTION 2026-10-15 밤 결정(Tripo 기본 제작 도구). Tripo가 만든 GLB를 사람 손 없이 게임 규격으로 정리하고 검사 자료까지 만든다. 서버(3.8GB)와 Claude 클라우드(Blender 다운로드 차단) 대신 GitHub Actions 러너에서 Blender를 쓴다.
흐름: tripo/<이름> 브랜치 결과(tripo-result/<이름>, .github/workflows/tripo.yml·tools/gen/tripo.py) 또는 incoming/*.glb → 자산 명세(.intake.json: id, kind=prop|tree|building|character, 목표 높이 m, 정면 방향, 상호작용 지점 이름·좌표 선택) → 러너에 Blender 4.2 LTS 설치(캐시) → tools/normalize.mjs(C066: 미터 단위·바닥 원점·삼각형 상한·팔레트 재질)로 정리 → 충돌 상자(AABB) 계산 → 정면·45도 미리보기 PNG(Cycles CPU 저샘플 또는 xvfb EEVEE) → intake-result/<이름> 브랜치(정리된 glb, png, report.json: 삼각형·크기·용량·실패 이유).
고칠 파일:
- .github/workflows/intake.yml (새)
