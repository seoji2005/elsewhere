# C015 애니메이션풍(원신 느낌) 시제품 — 판단용 (Claude 작업자)

목적: 사용자가 "원신 스타일로 갈지" 판단할 수 있게, 캐릭터 한 명 + 동네 한 블록을 애니메이션풍으로 바꾼 체험판.
사용자 불만: 지금 주인공의 몸·얼굴 움직임이 부자연스럽다. 동네 후보 3개도 마음에 안 든다(지금 셰이딩 기준).
조사(요약): VRM + @pixiv/three-vrm(MIT, 설치됨 3.5.5)이 표정·눈 깜빡임·시선·스프링 본(머리카락·옷 흔들림)·MToon(툰 셰이더+외곽선)을 준다.
모델: /home/dev/asset-packs/vroid-cc0/ (AvatarSample_F, Sendagaya Shino — VRoid 공식 샘플, CC0. LICENSE-NOTE.txt). 동작: /home/dev/asset-packs/q-anim (Quaternius UAL, CC0) → VRM 휴머노이드로 리타깃.
고칠 파일:
- src/main.ts, src/player/*.ts, src/scene/*.ts, src/render/*.ts
- src/anime/*.ts (새)
- assets/manifest.json, src/assets/* (vrm 줄인 파일 포함), tools/assets.mjs(VRM 텍스처 축소가 필요하면)
크기: 큼(≤400줄)
하지 말 것: sim·데이터 변경, 새 패키지(three-vrm 외), 커밋. 원래 모습은 `?style=current`로 남겨 비교 가능하게.
통과 기준:
1. `?style=anime`(기본): VRM 캐릭터 1명. 서기·걷기·뛰기(리타깃), 자동 눈 깜빡임, 가끔 미소, 카메라 쪽 시선, 머리카락·치마 스프링 본. 조이스틱 조작은 지금과 같게.
2. 동네: 지금 A 블록의 재질을 공유 툰 램프 셰이더(+외곽선은 비용 보고 결정)로, 밝은 애니메이션풍 팔레트·그라데이션 하늘·구름 카드. 해질녘 대신 맑은 늦은 오후도 시도(사용자 취향 비교용 `?time=day|dusk`).
3. 크기: VRM 텍스처 축소(썸네일 제거, 1024px 이하) → 모델 4MB 이하 목표, 빌드 10240KB 이하.
4. 성능: 보고에 빌드 크기·삼각형·그리기 호출. 폰 측정은 사용자가 `?debug=1`로.
