# C014 스크린샷 빠르게 (도구)

목적: 화면 작업의 병목인 서버 스크린샷(GPU 없음, CPU 2코어)을 빠르게. 지금은 한 장마다 새 페이지를 열어 셰이더 컴파일·에셋 해제를 반복한다.
고칠 파일:
- tools/shot.mjs
- src/ui/debug.ts (카메라 지정 훅만)
- tools/bench-shot.mjs (새 파일)
크기: 보통(≤150줄)
하지 말 것: 장면·조명·게임 동작 변경, 새 패키지, 커밋
통과 기준:
1. tools/shot.mjs: 같은 빌드에 대한 여러 장을 **한 페이지에서** 찍는다. 질의 문자열이 같은 샷은 카메라만 바꿔서 연속 촬영(장면 다시 로드 없음).
   샷 지정: `node tools/shot.mjs "look=b" "look=b@cam=x,y,z,tx,ty,tz"` 처럼 `@cam=`(카메라 위치·바라보는 점). 기존 사용법은 그대로 동작.
2. src/ui/debug.ts: `window.__shot = { setCamera(pos, target), frame(): Promise<void> }` 같은 최소 훅(디버그 전용, 게임 동작 변화 없음).
3. 렌더러 선택: `SHOT_GL=swiftshader|vulkan` 환경변수. vulkan은 Chromium `--use-angle=vulkan --enable-features=Vulkan` + Mesa lavapipe(설치됨). 안 되면 swiftshader로 되돌아간다.
4. tools/bench-shot.mjs: 같은 3개 샷을 (a) 지금 방식 (b) 한 페이지 방식 × (swiftshader, vulkan)으로 찍어 걸린 시간 표를 출력. 결과를 보고에. 가장 빠른 조합을 기본값으로.
5. 이미지가 정상(검은 화면·빈 화면 아님, 콘솔 오류 없음)인지 확인. `bash tools/check.sh --fast --card cards/C014.md` PASS.
   (Codex 샌드박스에서 브라우저가 안 뜨면 코드만 작성하고 보고에 적는다. 측정은 마스터가 한다.)
