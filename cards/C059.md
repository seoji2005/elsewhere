# C059 SD 얼굴 비율: 너무 크고 길다 (화면, Codex)
목적: 사용자(2026-10-15): "얼굴이 너무 커. 카툰이니까 커도 되는데 비율이 이상해. 너무 긴 거 같아." 원인(마스터): VRoid 얼굴은 어른 비율(긴 턱)인데 sd=2에서 머리만 2.1배 키워 긴 얼굴이 그대로 커짐.
고칠 파일:
- src/anime/avatar.ts
- src/anime/lise.ts (리세 시제품이 같은 비율을 쓰면)
크기: 작음(≤40줄)
참고(읽기만): cards/C041.md(비율·접지 수치 계산 방법), src/main.ts
하지 말 것: 접지 깨기(발바닥 ±3cm 유지), 옷 색·줄 세우기 변경, 새 패키지, 커밋
통과 기준:
1. sd=2: 머리 배율을 약 1.75~1.85로 낮추고, 얼굴(머리 뼈 아래 얼굴 메시)이 둥글게 보이도록 머리 뼈에 약한 비균일 배율(세로 ≈0.9 × 가로)을 주되 머리카락 스프링 콜라이더·시선이 깨지지 않게(R012: 콜라이더 반지름 보정, setInitState). 몸·다리는 등신 2.7~3.0 유지되게 재조정.
2. sd=1도 같은 원리로 세로 눌림 적용(머리 배율은 작업자 판단).
3. Node 임시 스크립트로 sd별 머리 높이·폭 비율(높이/폭), 등신, 발바닥 높이 숫자 보고. 목표: 얼굴 높이/폭이 지금보다 10~15% 작아짐.
4. `bash tools/check.sh --fast --card cards/C059.md` PASS(스크린샷은 마스터).
