# C004 시뮬레이션 기초

목적: M1 전체가 쓸 순수 TypeScript 바탕(렌더와 분리). 기능 자체(NPC 대화·주식 등)는 만들지 않는다.
고칠 파일:
- src/sim/clock.ts, src/sim/ledger.ts, src/sim/world.ts, src/sim/save.ts
- tests/sim/*.test.ts
- package.json (scripts 칸만: "test": "vitest run")
크기: 큼(≤400줄)
하지 말 것: 렌더·UI·three import, 새 패키지, 커밋, 다른 파일
통과 기준:
1. clock.ts: 게임 시각(일·시·분), 실제 1초당 게임 분 배속, 일시정지, 하루 경계 이벤트. 결정적(같은 입력 = 같은 결과).
2. ledger.ts: 계좌별 잔액, 모든 돈 이동은 거래 기록(id·시각·from·to·금액·사유)으로만. 같은 거래 id 두 번 = 무시(중복 정산 방지). 잔액 음수 금지(실패 반환).
3. world.ts: 사람(플레이어·NPC)·장소·회사를 id로 담는 상태. 관계 값 저장 자리(누가→누구, 숫자)만, 규칙은 없음.
4. save.ts: 전체 상태 JSON 직렬화/복원, version 필드, 알 수 없는 version은 오류.
5. tests: 각 파일 핵심 동작 + 중복 정산·음수·저장→복원 동일성. `bash tools/check.sh --fast --card cards/C004.md` PASS.
