# C005 NPC 일과와 관계 (시뮬레이션만)

목적: M1-11(NPC 5명 하루 일과), M1-12(대화와 관계 단계)의 로직. 화면·UI는 만들지 않는다.
고칠 파일:
- src/sim/npc.ts, src/sim/relationship.ts
- src/data/npcs.ts, src/data/places.ts
- tests/sim/npc.test.ts, tests/sim/relationship.test.ts
크기: 큼(≤400줄)
하지 말 것: 렌더·UI·three, 새 패키지, 기존 sim 파일 수정(필요하면 제안 칸에), 커밋
통과 기준:
1. 세계는 현실을 베끼지 않은 가상 사회다(DIRECTION.md). 장소 6~8곳(집들, 카페, 가게, 공원, 사무실 등)에 이 세계만의 이름.
2. npcs.ts: 이름·나이·직업·성격(2~3 특성)·좋아하는 것/싫어하는 것·하루 일과(요일별 시간대 → 장소)를 가진 NPC 5명. 서로 다른 생활 리듬.
3. npc.ts: whereIs(npc, GameTime) → 장소 id. 같은 NPC를 아침과 저녁에 다른 곳에서 만난다(테스트).
4. relationship.ts: 관계 값과 단계(낯섦 → 아는 사이 → 친구 → 호감 → 연인 첫 단계). 대화 선택지 하나가 성격·취향에 따라 값이 다르게 움직인다.
   단계마다 문턱값, 하루 상승 상한(같은 날 반복으로 뛰지 않게). 모든 상호작용은 기록(누가·언제·무엇·변화)으로 남긴다(나중에 기억·소문에 씀).
   C004의 world.ts 관계 저장 자리와 맞춰 쓴다(읽기만).
5. 테스트: 일과 위치, 선택지 반응 차이, 하루 상한, 단계 상승. `bash tools/check.sh --fast --card cards/C005.md` PASS.
