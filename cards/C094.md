# C094 시간 계약: 읽는 동안 멈춤 · 다음 일까지 넘기기 · 기본 속도 (Claude 클라우드 opus)
목적: docs/design/GDD.md §2 시간. 30분 시제품 안에 여러 영업일이 들어가고, 폰에서 읽는 동안 시간 압박이 없게.
고칠 파일:
- src/main.ts — 결폰 패널·대화(talk)가 열려 있으면 session.tick에 0초(멈춤). 화면에 작은 "멈춤" 표시.
- src/ui/hud.ts, src/ui/hud.css — 상단 바에 "다음 일까지 ▶▶" 버튼. 누르면 다음 일 시각과 이유를 한 줄로 보여 주고(예: "내일 07:00 아침까지", "14:00 상자 도착까지") 확인하면 넘긴다.
- src/game/session.ts — `nextEvent(): { minute, reason }`(후보: 21시 이후면 다음 날 07:00 / 영업 전이면 09:00 / 다음 배송 도착 / 다음 약속·소개팅 / 플레이어 근무 시작·끝 / 직원 근무 시작 — 가장 이른 것, 없으면 1시간 뒤), `skipTo(minute)`(기존 tick을 써서 모든 분을 그대로 처리 — 의무 누락 금지, 끝나면 저장). 새 게임 기본 속도 게임 2분/실제 1초(기존 세이브는 저장된 속도 유지).
- tests/game/time.test.ts (새) — skipTo 결과가 같은 분만큼 tick한 결과와 원장·가게·배송·급여까지 동일, nextEvent 후보 우선순위, 밤 21:30에 넘기면 다음 날 07:00, 넘기는 동안 배송 도착·급여 지급이 정확히 한 번.
- tests/play/time.mjs (새, 선택) — 결폰 열면 게임 시각이 안 움직이고, 넘기기 버튼으로 다음 날 아침이 된다.
크기: 보통(≤150줄; 테스트 포함 큼≤400 허용)
하지 말 것: 경제 규칙·숫자 변경, 기존 테스트 수정, tycoon 등록부 구조 변경, 새 npm 패키지.
