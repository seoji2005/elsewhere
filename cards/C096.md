# C096 직접 운반: 생산자에게 가서 상자 받아 오기 vs 배달 (Claude 클라우드 opus)
목적: docs/design/GDD.md §2 손 운영. 리테일 타이쿤의 "직접 물건 옮겨서 배달비 아끼기". 지금 orderStock은 24시간 뒤 자동 도착이다. 직접 가지러 가면 빠르고 싸지만 그동안 가게를 비운다(기회비용).
고칠 파일:
- src/game/tycoon/haul.ts (새 시스템 'haul') — 명령: `pickupOrder(producerId, itemId, qty)`: 생산자 원가 그대로(배달비 없음) 결제는 tycoonCore.settle, 상자 n개가 '들고 있는 짐'(최대 12개)으로 생김. 생산자 장소(그 주민의 지금 장소, 영업 시간 07~19시)에 플레이어가 있어야 함. `dropAtShop()`: 내 가게 안에서 짐을 뒷방(backroom)에 넣음. 짐 들고 있는 동안 이동 속도 −20%(main 이동에 노출할 값만). 배달(기존 orderStock)은 배달비 = 주문액 10%(최소 2결) — 생산자→배달원 역할 주민 계정으로 이체(돈 생성 없음), 도착은 그대로 다음 날.
- src/game/tycoon/registry.ts — haul 등록 한 줄.
- src/game/session.ts — orderStock에 배달비 다리 추가(기존 테스트 숫자가 바뀌면 보고하고 배달비를 옵션 기본 0으로 두고 새 게임만 켜기), 플레이어 이동 속도 배수 노출.
- src/ui/shop.ts, src/ui/hud.ts — 생산자 근처에서 "상자 받기"(품목·수량), 가게 안에서 "뒷방에 내려놓기", 상단에 짐 표시(📦×n). 내 가게 탭 주문 화면에 "직접 가지러 가기(배달비 0, 지금)" vs "배달(배달비 n결, 내일)" 두 버튼과 생산자 위치 안내.
- tests/game/haul.test.ts (새)
크기: 큼(≤400줄, 마스터 이유: 시스템·세션·UI)
하지 말 것: C087 수요·밸런스 숫자 변경, 기존 테스트 수정, 재고 복제(받기·내려놓기 중복 명령 무효), Math.random.
통과 기준(테스트): 받기→내려놓기 후 뒷방 수량 정확, 같은 명령 재실행 중복 없음, 생산자 장소 밖·영업 시간 밖 거부, 짐 상한, 배달비 이체·총액 보존, 저장 후 들고 있는 짐 복원, 틱 분할 동일. 플레이 시나리오(tests/play/haul.mjs): 가게 → 생산자 → 받기 → 가게 → 내려놓기 → 진열 → 판매가 3분 안. 폰 가로 스크린샷 2장(.shots-c096/) 직접 확인. `bash tools/check.sh --card cards/C096.md --fast` PASS(Blender·180일 시간 초과 환경 예외).
