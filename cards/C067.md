# C067 뉴욕풍 건물 키트 + 시험 블록 (Blender, Claude 작업자 opus)
목적: 세계 전체 통일감의 바탕. 화풍(과슈/툰)과 무관한 건물 형태를 Blender로 만든다. 재질은 이름(palette.json·과슈 텍스처 이름과 맞춤: wall_redbrick, wall_brownstone, wall_limestone, trim_cream, trim_dark, glass, door_green, awning, metal_dark …)으로만 지정해 두 화풍 모두 같은 모델을 쓴다.
기준 그림(읽기만): /home/dev/game-gen/batch3sheets-165626/g-facades-*.png, /home/dev/game-gen/batch1-153534/facades-*.png(건물 정면 시트), /home/dev/game-gen/batch2-154742/*.png(거리 분위기). docs/look/STYLE.md §5(상자 금지 4요소: 받침·오목한 창·코니스·수직 분절, 10m당 밀도), AGENTS.md "Blender 제작 원칙"(소품 규칙: Bevel segments 2, Weighted Normal, 정점 색 AO).
도구: Blender 4.2 헤드리스(`blender --background --python ...`, dev 계정), Building Tools 1.0.13(MIT, dev에 설치됨; add_floorplan은 헤드리스 동작, add_floors 등은 편집 모드 컨텍스트 필요 — 안 되면 bmesh로 직접), tools/normalize.mjs(C066 변환기, 필요하면 사용).
고칠 파일:
- tools/blender/buildings.py (새, 재실행 가능), tools/blender/*.py (공용 함수 새 파일 가능)

크기: 큼(≤400줄. 마스터 이유: 건물 6종과 시험 블록을 한 번에)
하지 말 것: 기존 코너 장면 변경(?block=1에서만), sim·ui 변경, 새 npm 패키지, 빌드 10240KB 초과, 커밋, 실제 브랜드.
통과 기준:
1. 건물 6종: 붉은 벽돌 워크업(비상계단), 브라운스톤(현관 계단 stoop), 석회석 모퉁이 상점(차양), 유리·철 사무실 저층부, 작은 극장(마키 차양·전구 자리), 세탁소 상점. 각 4~7층(극장·사무실은 예외 가능), 상자 금지 4요소 모두, 1층은 상점 진열창·문, 위층은 오목한 창(창틀·창턱), 지붕 코니스, 수직 분절(기둥·파이프). 1채 삼각형 8천 이하.
2. 시험 블록 `?block=1`: 6종을 섞어 거리 양쪽 약 80m(건물 높이·폭 변주, 같은 종류 연속 금지), 보도·차도·횡단보도, 가로등·소화전·벤치 정도의 단순 소품(STYLE §5 밀도 근처), 기존 플레이어가 걸을 수 있음. `?look=gouache`가 있으면(cl/c069가 합쳐진 뒤) 재질 이름으로 과슈 텍스처가 붙도록 이름을 맞춰 둔다(지금 main엔 과슈가 없으니 툰으로 확인).
3. 검수: 건물마다 Blender Cycles 저샘플 정면·45도 렌더 PNG(.shots/c067-<종류>-*.png)와 게임 GHA 샷(`block=1&spot=..` 또는 `@cam=`으로 거리 눈높이 3장, time=day·dusk) — 직접 보고 상자처럼 보이는 곳·떠 있는 곳·각진 모서리를 최대 3라운드 고친다.
4. 서버 `bash tools/check.sh --card cards/C067.md` PASS.
