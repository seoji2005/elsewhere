# C025 세션에 생성 주민 넣기 (로직만, Codex)
목적: M1-17. C024 게임 세션은 핵심 주민 6명만 다룬다. 새 게임마다 시드로 만든 생성 주민(npcgen, 50명+)도 세계에 들어가 일과대로 움직이고, 만남·소개팅 약속이 생성 주민과도 처리되게 한다.
고칠 파일:
- src/game/session.ts
- tests/game/session.test.ts
크기: 작음(≤40줄)
참고(읽기만): src/sim/npcgen.ts(generate), src/sim/npc.ts, src/sim/matchmaking.ts, src/data/npcs.ts
하지 말 것: 다른 파일 수정(필요하면 제안), 화면, 새 패키지, 커밋
통과 기준:
1. 새 세션은 시드(저장됨)로 생성 주민을 만들어 world.people에 넣는다. 이어 하기 때 같은 시드로 같은 사람들이 다시 만들어진다(주민 목록 자체를 저장본에 크게 넣지 않아도 됨, 판단은 보고에).
2. tick에서 생성 주민도 whereIs로 장소가 갱신되고, 약속 처리에서 생성 주민을 찾는다(지금은 핵심 주민만 찾아 생성 주민 약속이 영원히 남음).
3. 테스트: 같은 시드 → 같은 주민, 다른 시드 → 다름, 생성 주민과의 약속이 처리됨, 이전 v2 저장본(시드 없음) 처리.
4. `bash tools/check.sh --fast --card cards/C025.md` PASS.
