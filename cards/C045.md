# C045 얼굴 SDF 그림자 텍스처를 3D 얼굴에서 자동 생성하는 도구 (도구, Codex)
목적: 리세 렌더링 준비(R016a·R016b). 원신식 얼굴 그림자에는 각도별 그림자 마스크 8~16장을 손으로 그려 SDF로 합치는데, 우리는 그릴 사람이 없다. VRoid 얼굴 메시를 UV 공간에 래스터화하고, 빛 각도마다 (손질한) 법선으로 밝음/어둠 마스크를 CPU로 계산한 뒤 R016a의 sdfBake로 SDF 텍스처를 만든다.
고칠 파일:
- tools/face-sdf.mjs (새)
- tools/assets.mjs (필요하면 호출 연결만)
크기: 보통(≤150줄)
참고(읽기만): /home/dev/research/R016a/report.md·modules/sdfBake.ts·faceSdf.ts, /home/dev/research/R016b/report.md(얼굴 맵 규격: RG=좌/우 SDF, B=법선 복귀, A=강도, 선형·mip 없음·flipY=false), /home/dev/asset-packs/vroid-cc0/(Shino·AvatarSample_D 얼굴), GGXrd GDC 2015 개념(얼굴 법선을 구·타원체 쪽으로 손질)
하지 말 것: 게임 src 변경(이번엔 텍스처 생성만), 새 패키지(node_modules에 있는 three·meshoptimizer 등만), GPU 의존(서버엔 GPU 없음), 커밋
통과 기준:
1. `node tools/face-sdf.mjs <vrm> <out.png> [--size 512]`: Face 메시(F00_000_00_Face_00_SKIN 재질 primitive)의 UV에 삼각형을 래스터화, 정점 법선을 머리 중심 기준 타원체 법선과 섞어 매끈하게(섞는 비율 옵션), 빛 수평각 0°→180° N장(기본 16)의 lit 마스크 → 좌/우 SDF(RG), A=1, B=0. PNG(무손실) 출력.
2. 서버 Node에서 512px 30초 이내. 결과 PNG 경로와, 각도 몇 개의 마스크 미리보기 PNG를 /tmp에 저장해 보고(마스터가 눈으로 확인).
3. 검사: 첫 마스크 모두 밝음·끝 마스크 모두 어둠, 각도가 늘수록 밝은 영역이 줄어듦(단조성)을 스크립트 안에서 assert.
4. `bash tools/check.sh --fast --card cards/C045.md` PASS.
