# C066 에셋 스타일 변환기 (도구, Codex)
목적: 출처가 다른 3D 에셋(Meshy·Tripo GLB, 무료 CC0 모델, 우리 Blender 코드 결과)을 STYLE.md 규칙으로 통일해 게임에 넣는 단일 관문. 세계 전체 통일감(사용자 2026-10-15)의 핵심 장치.
고칠 파일:
- tools/blender/normalize.py (새: Blender 헤드리스 스크립트), tools/normalize.mjs (새: 실행·검사 래퍼)
- docs/look/palette.json (새: STYLE.md §2 팔레트를 이름→hex로)
- tests/tools/normalize.test.ts (새, 가능한 범위)
크기: 보통(≤150줄. 넘치면 멈추고 남은 부분 보고)
참고(읽기만): docs/look/STYLE.md(§2 팔레트, §3 선, §5 형태, §10 보강), AGENTS.md "Blender 제작 원칙", tools/assets.mjs, tools/blender/lise.py(cl/c061 브랜치 — bpy 사용 예)
하지 말 것: 게임 src 변경, 새 npm 패키지, 커밋. Blender 애드온 설치.
통과 기준:
1. `node tools/normalize.mjs <in.glb> <out.glb> --kind prop|building|tree --height <m>`: Blender 헤드리스로 ① 실측 높이로 크기·바닥 기준점 맞춤 ② 폴리곤 예산(prop ≤3k, tree ≤5k, building ≤8k 삼각형)으로 Decimate ③ Weighted Normal + 작은 Bevel(segments 2, 가능한 경우) ④ 텍스처를 색 군집(k-means 4~6색)으로 나눠 각 군집을 palette.json의 가장 가까운 이름 색으로 바꾼 평면색 재질(텍스처 제거, 구운 그림자 제거) ⑤ 정점 컬러 AO 베이크(선택, 시간 되면) ⑥ GLB 내보내기.
2. 결과 보고 JSON: 삼각형 전후, 쓴 팔레트 이름, 크기.
3. 시험: Blender 기본 도형으로 만든 임시 GLB 2개(텍스처 있는 것 1개 포함)로 돌려 위 1·2가 맞는지 확인(실제 Meshy 파일은 나중에 마스터가).
4. `bash tools/check.sh --fast --card cards/C066.md` PASS.
