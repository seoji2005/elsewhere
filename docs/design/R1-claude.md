## 1. 한 줄 콘셉트와 디자인 원칙

**한 줄:** 골목 가게 계산대에서 시작해, 손님·이웃·라이벌이 건네는 기회를 붙잡아 반도체 공장 회의실까지 가는 경영 인생 게임 — 커질수록 손에서 놓는 일과 새로 쥐는 일이 바뀐다.

### 원칙 1. 커질수록 할 일이 바뀐다 (사라지지 않는다)
- 단계가 오를 때 아래 단계 일은 직원에게 넘어가지만, **넘긴 일은 '사건'으로 돌아온다**(직원 실수·지각·이직, 라이벌의 수, 도시 사건). 플레이어의 하루는 항상 "결정 카드 3~5장"으로 차 있어야 한다.
- 판정 질문: "이 기능이 생기면 플레이어가 할 일이 줄어드는가, 바뀌는가?" 줄어들기만 하면 빼거나 대가를 붙인다.

### 원칙 2. 해금 대신 기회
- "돈 X결이 있으면 이 사업 가능"은 어디에도 없다. 모든 새 사업·새 장소·새 앱은 **세계 안의 누군가·무언가가 건네는 기회 카드**로 열린다.
- 진짜 장벽은 사람(인재·신뢰), 허가, 기술, 거래처, 투자자 설득이다. 돈은 **속도와 규모만** 바꾼다(빨리 뽑기, 중고 대신 새 설비, 두 번 시도할 여유).
- 판정 질문: "이 조건이 숫자 하나(잔액)로 풀리는가?" 그렇다면 고친다.

### 원칙 3. 돈은 쓰는 재미
- 번 돈은 집·문화·차·수집품·기부로 흘러가고, 그곳에서 **사람·기회·컨디션·모임**이 열린다. 소비는 다음 사업의 입구다.
- 억지 유지비로 빼앗지 않는다. 유지비는 현실감 있는 최소한만, 안 내도 "사라짐"이 아니라 "멈춤"이다.
- 돈은 사라지지 않고 누군가에게 간다(장부 보존). 내가 쓴 돈이 재즈바 사장·집주인·작가의 수입이 되고, 그들의 삶이 바뀌는 것이 보인다.

### 원칙 4. 인과가 보이는 세계
- 모든 사건에는 앞선 원인이 있고, 원인은 미리 단서로 보인다(뉴스·손님 대사·지도 표시). "갑자기 운 나쁨"은 금지, "그래서 그랬구나"가 목표.
- 결과는 숫자보다 **사람의 말**로 먼저 온다. 광고 효과는 "전단 보고 왔어요", 위생 점검은 "요즘 그 집 바닥이 좀…" 소문으로.
- 정보는 비대칭이다. 알려면 가 보거나, 묻거나, 사람을 써야 한다.

### 원칙 5. 폰에서 10분 판단
- 한 번 켜면 10분 안에 "의미 있는 결정 하나 + 손맛 있는 운영 몇 분 + 결과 확인"이 끝나야 한다.
- 자주 하는 조작은 두 번 탭 안. 글은 두 줄 안. 한 손 세로·가로 모두.
- 플레이어가 없을 때 세계는 크게 무너지지 않는다. 대신 "돌아오면 결정할 것"이 쌓인다(켜 두면 돈이 아니라, 켜 두면 결정 대기).

### 2.2 네 가지 루프
**1분 — 손 운영.** 계산대에서 손님 줄을 처리하고(탭 = 계산), 흥정꾼에게 답하고, 비어 가는 진열대에 뒷방 재고를 채우고, 주차 빌런에게 말을 건다. 보상은 즉시: 손님 한마디, 매출 숫자 튀어 오름, 단골 게이지.

**하루 — 영업일.** 아침(07~09): 도매시장 직접 운반 또는 배달 주문, 오늘 날씨·뉴스·유행 확인, 직원 배치. 낮(09~21): 손 운영과 돌아다니기(이웃·라이벌 가게 염탐·기회 손님 대화). 마감: 결산 한 장(매출·원가·임대·급여·순이익, 손님 한마디 베스트 3, 내일 단서 1개).

**한 주 — 경영 판단.** 일요일 밤 "주간 회의"(폰 한 화면): 가격 정책, 광고 집행, 직원 승진·교체, 전문가 고용, 기회 카드 수락·거절, 라이벌 대응. 결정 3~5개, 각 결정은 다음 주 사건으로 결과가 보인다.

**한 시즌(4주) — 확장.** 시즌 끝에 "시즌 리뷰": 상권 지도 변화, 라이벌 순위, 금리·정책 발표, 새 무대(지점·도시·세계)로 가는 큰 기회 1~2장. 시즌은 실제 약 3~4시간 플레이.

## 3. 기둥별 상세 규칙과 숫자 초안

### 3.1 손 운영

**시제품 경제 숫자(1단계)**
| 항목 | 초안 | 비고 |
|---|---|---|
| 시작 자금 | 600결 (새 게임만) | 기존 세이브는 지금 잔액 유지 |
| 객단가 | 10~14결 | 차 8·빵 10·수프 15·목도리 25 (지금 품목 그대로) |
| 하루 손님 | 상권 유동 인구 × 유입률. 골목 기본 35~60명 | 3.2 손님 유형이 섞여서 온다 |
| 원가 | 도매가 = 정가 × 0.25 (지금 `procure` 규칙) | 직접 운반 시 도매시장 가격 −10% |
| 새 가게 하루 임대료 / 보증금 | 30결 / 300결 | 새 매물 ID로 추가. 기존 `cafe-unit`·`shop-unit`은 숫자 유지(세이브 검증과 일치) |
| 알바 시급 | 5~8결 (8시간 40~64결) | 능력·성격에 따라 요구 시급이 다름 |
| 하루 순이익 목표 | 150~250결 | 1주 ~1,200결 |

**직접 판매(계산대).**
- 플레이어가 계산대 반경 안에 있으면 직원이 없어도 손님을 받는다(지금 코드의 "직원 없으면 손님 없음" 규칙을 "직원도 사장도 없으면 손님 없음"으로 바꾼다).
- 손님은 대기열에 서고, 머리 위에 인내 막대가 보인다. 인내 = 유형별 4~15 게임분(손 운영 모드에선 실제 8~30초).
- 탭 1번 = 계산. 탭 대신 길게 누르면 **추천**("이것도 같이 드릴까요?"): 성공 확률 = 35% + 단골 10% − 급한 손님 20%. 성공 시 객단가 +40%.
- 사장이 직접 계산하면 손님 만족 +1(직원 평균 0). 단골 게이지는 사장 계산 때만 2배로 오른다 → 초반 손 운영의 이유.
- 직원 계산 속도 = 게임 3분 × (1.5 − 손/100). 손 50인 알바는 3분, 손 90인 베테랑은 1.8분.

**진열.**
- 진열대 칸 6개 × 선반 2개. **눈높이 칸**(위 선반 가운데 2칸)은 판매 확률 +30%, **계산대 옆 칸**은 충동구매(추천 없이 +1품목 15%).
- 손님이 물건을 집었다 놓으면 "흐트러짐"이 1 쌓인다. 흐트러짐 5 이상이면 그 선반 판매 −20%. 탭으로 정리(실제 1초). 직원은 눈 능력에 비례해 자동 정리.
- 품절 칸은 빈칸으로 보이고 손님 불만 `missing`. 뒷방 재고가 있는데 품절이면 손님 대사가 다르다: "뒤에 있지 않아요?"(사장이 직접 채우는 동기).

**직접 운반(배달비 아끼기).**
| 방법 | 비용 | 시간 | 용량 | 특이 |
|---|---|---|---|---|
| 배달 주문 | 주문액의 10% (최소 5결) → 배달업자 계정으로 이체 | 다음 날 07시 도착 | 무제한 | 지금 `orderStock` 그대로 + 배달비 |
| 손수레 직접 운반 | 0 | 도매시장 왕복 게임 40분(06~10시만 열림) | 20개 | 도매가 −10%, 직접 고르면 신선도 '상'(만족 +1, 하루 더 안 상함) |
| 경차(돈 쓰는 삶 3.9에서 삼) | 기름값 왕복 3결 | 왕복 25분 | 60개 | 이웃 동네 도매상까지 가능 → 새 품목 기회 |
| 직원 심부름 | 직원 시간 소모 | 왕복 50분 × (1.5 − 손/100) | 20개 | 성실 낮으면 늦거나 덜 사 옴 |

- 운반 중 길에서 만나는 사람(이웃·라이벌 직원·기회 손님)이 있다. 운반은 배달비 절약 + **우연한 만남의 시간**이다.
- 신선 품목(빵·수프)은 2일 지나면 폐기(돈은 이미 원가로 나갔으니 장부 변화 없음, 재고만 감소).

**주차.**
- 가게 앞 주차 칸 2개. 차로 오는 손님(가족·큰손·업자)은 빈칸이 없으면 30% 확률로 그냥 지나감.
- 주차 빌런(3.2)이 한 칸을 몇 시간 차지. 대응: 말 걸기 / 안내판 설치(소품 15결, 빌런 확률 −50%) / 구청 신고(과태료는 빌런 → 시 계정 이체, 동네 소문 '깐깐한 가게' 평판 학생·어르신층 −) / 근처 유료 주차장 제휴(손님 1명당 1결).

**손 운영은 위 단계에도 남는다.** 2단계: 새 지점 개업 첫날 직접 계산하면 그 지점 초기 평판 +10. 3단계: 공장 라인을 직접 돌아보면 수율 문제 원인 1개 발견. 4단계: 입찰 발표 무대에 직접 선다(5.3).

### 3.2 손님 개성 유형 (14종)

데이터 구조(새 파일 `data/patrons.ts`):
```ts
interface PatronType {
  id: string; name: string;
  segment: 'student'|'worker'|'family'|'senior'|'tourist'|'rich'|'trade';
  weight: (ctx: AreaContext) => number;      // 시간대·날씨·상권·평판에 따른 등장 가중치
  patience: [number, number];                // 게임분
  priceTolerance: number;                    // 정가 배수
  basket: [number, number];                  // 품목 수
  car: number;                               // 차로 올 확률
  quirk: QuirkId;                            // 행동 훅 하나
  lines: { enter: string[]; happy: string[]; angry: string[] };
}
```
이름 없는 손님은 상권 손님층 계정(`crowd:student` 등, 3.11)에서 돈을 내고, 이름 있는 주민은 자기 지갑에서 낸다. 같은 손님 ID는 하루 한 번(`visitId` 규칙 유지).

**① 단골 (모든 층)**
- 등장: 같은 주민이 3회 이상 만족 구매하면 단골이 된다. 단골 수 = 가게의 바닥 매출.
- 행동: 늘 사는 품목이 있다. 없으면 실망하지만 떠나진 않는다. 3회 연속 품절이면 발길이 끊긴다. 가끔 **기회를 가져온다**(직업에 따라).
- 대사: "늘 그걸로요." / "요즘 앞집 생겼던데, 난 여기가 좋아." / "사장님, 혹시 아는 회계사 있어요? 우리 사무실이…"
- 영향: 매출 안정(날씨·유행 영향 절반), 기회 원천 1순위, 소문 전파 시 호의.

**② 큰손 (부유층)**
- 등장: 상권에 부유층 비중이 있거나 고급 광고·평판 30 이상. 주 1~2회.
- 행동: 한 번에 5~10품목, 가격 용인 1.6배. 주차 칸 필요. 응대가 늦으면 바로 떠나고, 만족하면 "선물용으로 30개" 같은 대량 주문을 남긴다.
- 대사: "여기 있는 거 다 하나씩 싸 주세요." / "주차할 데가 없네요." / "다음 주 모임에 쓸 건데, 서른 개 되나요?"
- 영향: 하루 매출 급등, 대량 주문 = 재고·운반 판단 문제, 놓치면 "그 집 별로더라" 부유층 소문.

**③ 주차 빌런 (직장인·업자)**
- 등장: 주차 칸이 있고, 근처 회사·공사장이 있으면 오전 등장 확률 25%/일. 도로 공사 사건 때 2배.
- 행동: 물건은 안 사거나 생수 하나 사고 3~5시간 주차. 말 걸면 성격에 따라 순순히 빼거나(40%) 버티거나(40%) 시비(20%).
- 대사: "잠깐이면 돼요, 금방 빼요." / "자리 비어 있었는데 뭐가 문제예요?" / "여기 사장 땅이에요? 아니잖아요."
- 영향: 차 손님 놓침, 대응 방식이 평판에 남는다. 해결 과정 자체가 이야기(나중에 그 빌런이 동네 건물주로 밝혀질 수도).

**④ 진상 (모든 층, 소수)**
- 등장: 기본 3%. 가격을 올렸거나 품절이 잦으면 증가. 비 오는 날 짜증 +.
- 행동: 환불·서비스 요구, 큰 소리. 응대 선택지 3개(사과+서비스 / 원칙대로 / 단호히 거절). 다른 손님들이 지켜본다.
- 대사: "어제 산 빵이 딱딱하던데요?" / "사장 나오라 그래요." / "리뷰 어떻게 쓰는지 보세요."
- 영향: 응대에 따라 평판 −5~+3. 원칙대로 응대 + 주변 손님 공감 시 오히려 "사장 멋있다" 소문. 진상 리뷰는 SNS 앱에 실제로 뜬다.

**⑤ 학생 무리 (학생)**
- 등장: 학교·학원 있는 상권 15~18시. 3~5명 묶음.
- 행동: 객단가 낮음(가격 용인 0.9), 한꺼번에 와서 계산대 줄을 막고, 흐트러짐 3 남김. 맛있으면 SNS에 올린다(확산 확률 20%).
- 대사: "야 이거 맛있대!" / "사장님 이거 천 원만 깎아 주시면 안 돼요?" / "여기 사진 찍어도 돼요?"
- 영향: 매출보다 **확산**. 유행 품목 하나를 만들 수 있다. 줄이 길어지면 다른 손님 인내 감소.

**⑥ 흥정꾼 (어르신·업자)**
- 등장: 시장 근처·어르신 비중 높은 상권. 가격을 정가보다 10% 이상 올리면 증가.
- 행동: 계산 때 할인 요구. 선택: 깎아 줌(−10%, 다음에 또 옴) / 덤 하나(원가 손해, 단골화 +) / 거절(30% 그냥 감).
- 대사: "에이, 여기서 오 결만 빼 줘." / "저 앞집은 더 싸던데?" / "단골 할 테니까 덤 하나만."
- 영향: 가격 정책의 거울. "저 앞집은 더 싸던데"는 라이벌 가격 정보의 단서다(정보 비대칭).

**⑦ 구경꾼 (관광객·학생)**
- 등장: 유동 인구 많은 대로, 주말.
- 행동: 오래 둘러보고 안 사는 경우 70%. 흐트러짐 2. 진열이 예쁘면(눈높이 칸 구성·조명 소품) 구매로 전환 +20%.
- 대사: "구경만 할게요~" / "와, 이 가게 예쁘다." / "다음에 올게요."
- 영향: 진열의 가치를 보여 준다. 전환되면 관광객 리뷰.

**⑧ 리뷰어·동네 인플루언서**
- 등장: 평판 20 이상 또는 SNS 광고 후 3일 안. 주 0~1회. 겉모습으로 알아보기 어렵다(사진 찍는 행동이 단서).
- 행동: 1개 사고 사진. 그날 만족도(대기 시간·품절·청결)가 리뷰 점수.
- 대사: "여기 시그니처가 뭐예요?" / "(찰칵) 조명 좋네요." / "솔직히 기대보다 별로네요."
- 영향: 리뷰 1건이 다음 3일 유입 ±15%. 광고 '대박'의 실제 원인이 되기도 한다.

**⑨ 급한 직장인 (직장인)**
- 등장: 오피스 상권 08~09시, 12~13시 몰림.
- 행동: 인내 4분. 정해진 1품목. 빠르면 다시 온다(단골 전환 빠름).
- 대사: "빨리요, 회의 늦었어요." / "카드요, 영수증 안 주셔도 돼요." / "어제보다 빨라졌네."
- 영향: 피크 시간 손 운영 압박의 주역. 직원 '손' 능력의 가치를 보여 준다.

**⑩ 수다쟁이 이웃 할머니 (어르신)**
- 등장: 주거 상권 오전. 이름 있는 주민(생성 주민 중 '살뜰한 돌봄형' 원형).
- 행동: 사는 건 적고 말이 많다. 대화하면 **동네 소문 1개**(라이벌·건물주·공사·사건 단서). 무시하면 서운함(호감 −).
- 대사: "내가 이 동네 사십 년 살았는데…" / "앞집 사장 말이야, 빚이 많대." / "다음 달에 저 건물 헐린다더라."
- 영향: 정보 비대칭을 푸는 인간 정보원. 소문은 정확도 60~80%.

**⑪ 관광객 (관광객)**
- 등장: 역·명소 근처 상권, 축제 사건, 환율이 이 나라에 유리할 때 증가.
- 행동: 가격 둔감(1.3배), 기념품성 품목 선호, 말이 잘 안 통해 응대 시간 1.5배.
- 대사: "이거, 이 동네 특산이에요?" / "사진, 같이 괜찮아요?" / "다음 여행 때 또 올게요!"
- 영향: 환율·축제와 이어지는 매출 변동. 세계 단계 '해외 브랜드 인지도' 씨앗.

**⑫ 좀도둑**
- 등장: 기본 1%. 진열대가 계산대에서 안 보이는 배치, 직원 '눈' 낮음, 붐비는 시간에 증가.
- 행동: 1~2품목 슬쩍. 발견 확률 = 사장 있음 60% / 직원 눈/150. 발견 시 선택(돌려받고 보냄 / 신고 / 사정 듣기 — 배고픈 학생이면 이야기가 열림).
- 대사: (발각 시) "아… 그냥 보기만 한 건데요." / "죄송해요, 한 번만…" / "신고하면 저 학교 잘려요."
- 영향: 재고 손실(장부 변화 없음, 재고만 감소). 보안 소품·배치 결정. '사정 듣기'는 나중에 그 학생이 알바 지원자로 오는 사건.

**⑬ 점검원·바이어 (위장 손님)**
- 등장: 위생 불만 누적(3.8 사건) 또는 기업 납품 기회 직전. 평범한 손님처럼 보임.
- 행동: 청결·유통기한·응대 확인. 결과는 다음 날 통지.
- 대사: "여기 손 씻는 곳 어디예요?" / "이 빵 언제 구운 거예요?" / "명함 하나 드려도 될까요?"
- 영향: 점검 통과 = 평판 +, 실패 = 영업정지 1일 + 과태료(가게 → 시 계정). 바이어 만족 = B2B 기회 카드.

**⑭ 기회 손님 (특수 직업 주민)**
- 등장: 단골·이웃 중 직업이 연구원·엔지니어·투자자·공무원·업체 대표인 주민. 신뢰 20 이상이면 "사적인 이야기"를 꺼냄.
- 행동: 평범하게 사다가 어느 날 고민을 말한다. 대화 선택으로 기회 카드가 생긴다(4절).
- 대사: "요즘 연구실 지원이 끊겨서요…" / "사장님 같은 사람이 투자자면 좋겠다." / "우리 회사가 납품처를 바꾸려는데, 관심 있어요?"
- 영향: 산업 문을 여는 열쇠. 같은 사람이라도 신뢰가 쌓여야 말한다.

**손님층 비중이 상권마다 다르다.** 손님 유형 가중치 = 상권 손님층 비중 × 유형 기본 가중치 × 사건 배수 × 평판 배수. 시제품 골목: 직장인 30·학생 25·어르신 20·가족 15·관광객 5·부유층 5.

### 3.3 직원

**능력 4개 (0~100, 생성 시 시드로 결정, 성장함)**
| 능력 | 효과 |
|---|---|
| 손 | 계산·진열·운반 속도 |
| 눈 | 실수 확률, 흐트러짐 정리, 좀도둑·유통기한 발견 |
| 말 | 손님 만족, 추천 성공률(10~30%), 진상 응대 결과 |
| 성실 | 지각·결근·근무 중 딴짓 |

**성격:** 지금 원형 10종(`data/archetypes.ts`)을 그대로 쓴다. 원형마다 직장 성향 하나를 더한다.
| 원형 | 직장 성향 |
|---|---|
| 차분한 반전형 | 실수 적음, 손님 응대 무난, 칭찬에 약하게 반응 |
| 다정한 수다형 | 말 +10, 단골 빨리 만듦, 근무 중 수다(속도 −10%) |
| 무뚝뚝한 장인형 | 손·눈 +, 말 −, 승진 욕심 없음, 충성 높음 |
| 호기심 탐색형 | 성장 빠름(경험치 ×1.3), 지루하면 이직 |
| 조용한 몽상형 | 진열 감각(눈높이 칸 효과 +10%), 피크 시간 약함 |
| 장난스러운 분위기형 | 학생 손님 만족 +, 진상과 잘 싸움 |
| 꼼꼼한 계획형 | 실수 최저, 재고 관리 자동 제안 |
| 살뜰한 돌봄형 | 다른 직원 사기 +5, 과로 잘 숨김 |
| 건조한 농담형 | 위기 때 사기 유지, 손님 호불호 갈림 |
| 즉흥 발명형 | 가끔 개선 제안(신메뉴 기회 카드), 가끔 큰 실수 |

**사기(0~100):** 시작 60. 매일 변동 = 급여 공정(상권 평균 대비 ±) + 칭찬(+3, 하루 1번) + 과로(8시간 초과 시간당 −2) + 사장과의 관계(신뢰 축 변화를 따라감) + 동료 분위기. 사기는 bonds의 신뢰·존중 축과 별도로 두되, 해고·칭찬은 bonds에도 이벤트를 남긴다(지금 `fireEmployee`처럼).

**사건 확률 (하루마다 시드 키 `staff:${id}:${day}:${kind}`로 굴림)**
| 사건 | 확률 | 결과 |
|---|---|---|
| 지각 | (100 − 성실)/400 + 비 3% + 사기 40 미만 5% | 30~90분 늦음, 그 시간 계산대 비어 있음 |
| 결근 | 지각 확률의 1/4 | 하루 빈자리. 성실 높은 직원이 대신 나오기도 |
| 계산 실수 | 거래마다 (100 − 눈)/1,000 × 피로 배수 | 거스름돈 오류 = 손님 → 가게 혹은 반대 방향 이체(돈 생성 없음), 손님 불만 |
| 발주 실수 | 주 1회 (100 − 눈)/300 | 0을 하나 더 붙여 주문(재고 폭증) 또는 빠뜨림 |
| 진상과 다툼 | 진상 응대 시 (100 − 말)/200 | 평판 −3, 직원 사기 −10 |
| 이직 의사 | 사기 30 미만 5일 연속, 또는 라이벌 제안(3.6) | 2일 전 통보 문자. 붙잡기 선택지(시급 인상·대화·승진 약속) |
| 개선 제안 | 즉흥 발명형·호기심형, 주 5% | 신메뉴·진열 아이디어 = 작은 기회 카드 |

**성장과 승진:** 근무 1시간당 경험치 1. 50 경험치마다 가장 많이 쓴 능력 +3(최대 95). 승진 단계: 알바 → 정직원(근속 7일) → 점장(말+눈 ≥ 140, 신뢰 40, 근속 20일) → 지역 본부장(점장 실적 2시즌) → **자회사 대표**(기회 카드 "이 사업 네가 맡아 볼래?"로만). 점장은 매장 주간 보고를 직접 써서 결폰 인사 앱에 올린다(말투는 원형대로).

**첫 알바생 서사:** 게임 첫 알바생은 '서사 직원' 플래그를 가진다. 근속·신뢰가 쌓이면 시즌 2에 "저도 뭔가 해 보고 싶어요" 대사 → 갈림길 카드: (가) 자회사 대표로 세움(지분 10~30% 넘김, 그 자회사는 그의 성격대로 운영) / (나) 붙잡음(사기 −, 이직 위험) / (다) 응원하며 독립 → 관계 좋으면 협력 라이벌(공급 계약·공동 구매), 관계 나쁘면 진짜 라이벌(손님·직원 빼 감). 이 사람이 3.6 라이벌 넷과 별도인 **다섯째 라이벌 후보**다.

**직원 빼 가기·빼 오기:** 능력 합 280 이상 직원은 라이벌의 표적. 라이벌 제안 = 시급 +30%. 수락 확률 = 30% − 사기/3 + (시급 차)×2%. 반대로 플레이어도 라이벌 직원에게 메신저로 제안할 수 있다(bonds 신뢰 15 이상 필요 — 지금 `jobOffer` 규칙과 같음).

### 3.4 광고

**손님층 6개:** 학생, 직장인, 가족, 어르신, 관광객, 부유층. (B2B 단계에서 '기업'이 추가)

**채널 8개 (비용은 1단계 기준, 커지면 범위가 넓어짐)**
| 채널 | 비용 | 도달(명) | 반응 지연 | 효과 반감기 | 학생 | 직장인 | 가족 | 어르신 | 관광객 | 부유층 |
|---|---|---|---|---|---|---|---|---|---|---|
| 전단 | 40결/500장 | 500 | 당일 | 2일 | 0.6 | 0.8 | 1.2 | 1.4 | 0.3 | 0.3 |
| 현수막 | 120결/주 | 상권 유동 인구의 40% | 1일 | 7일(걸려 있는 동안) | 0.7 | 0.9 | 1.0 | 1.1 | 0.8 | 0.5 |
| 버스 광고 | 600결/2주 | 4,000 | 2일 | 5일 | 1.2 | 1.1 | 0.8 | 1.0 | 0.9 | 0.3 |
| 검색 광고 | 클릭당 2결, 하루 상한 설정 | 검색 수요만큼 | 당일 | 0(끄면 끝) | 0.9 | 1.3 | 1.1 | 0.4 | 1.2 | 1.0 |
| SNS 광고 | 30결/일 | 1,200/일 | 당일 | 1일 | 1.5 | 1.0 | 0.7 | 0.2 | 1.1 | 0.6 |
| 유튜버·인플루언서 | 300~3,000결/건 | 구독자 수 | 1~3일 | 10일 | 1.5 | 0.9 | 0.8 | 0.3 | 1.3 | 0.9 |
| TV | 2만 결~ (도시 단계) | 도시 인구의 30% | 3일 | 14일 | 0.6 | 0.9 | 1.3 | 1.5 | 0.8 | 1.0 |
| 스포츠 후원 | 시즌 계약 5,000결~ | 경기 관중·중계 | 7일 | 28일 | 1.1 | 1.2 | 1.2 | 0.9 | 0.6 | 0.8 |

- 지역 채널(전단·현수막)은 동네 단계부터, 버스·검색·SNS·유튜버는 가게가 하나만 있어도 쓸 수 있다. TV·스포츠 후원은 **비용 때문이 아니라** 방송국 광고 영업 담당·구단 관계자가 기회 카드로 연락해 와야 열린다(원칙 2).

**메시지 5종:** 가격("오늘만 반값") / 품질("새벽에 직접 고른 재료") / 감성("골목의 작은 불빛") / 재미(밈·이벤트) / 신뢰("동네 40년 할머니도 오는 집"). 손님층별 메시지 배수(0.6~1.4): 학생은 재미·가격, 직장인은 가격·품질, 가족은 신뢰·품질, 어르신은 신뢰·가격, 관광객은 감성·재미, 부유층은 품질·감성.

**모델 4종:** 없음(×1.0, 위험 0) / 직원(×1.1, 직원 사기 +10, 위험 0.5%) / 동네 유명인(×1.3, 위험 2%) / 연예인(×1.8, 위험 4%, 도시 단계·기회 카드로만). 모델 사고 = 음주·논란 사건 → 역풍.

**효과 공식:**
```
기대 신규 방문 = 도달 × 상권도달률 × Σ_층(상권 층 비중 × 채널 적합 × 메시지 배수) × 모델 배수 × 준비도 × 운
준비도 = 0.5 + 0.5 × min(1, 진열 충족률) × (평판+100)/200 × 2   (최대 1.0, 품절·나쁜 평판이면 반토막)
상권도달률 = 채널이 이 가게 손님 동선과 겹치는 정도 (전단 0.04, 현수막 0.06, SNS 0.02, 버스 0.01 …)
```
**운 굴림:** `u = rng(seed, "ad:" + 캠페인ID)`.
| 결과 | 확률 | 운 배수 | 예시 |
|---|---|---|---|
| 역풍 | 2% + 모델 위험 + (메시지 '재미' 1%) + (가격 메시지인데 실제 가격이 비쌈 3%) | −0.5 (기존 손님층에서 이탈) + 평판 −5~−15 | 연예인 모델 음주 운전 → "불매합니다" 댓글, 어르신층 이탈 |
| 무반응 | 25% − 10% × (평균 적합 − 1) | 0.1 | 어르신 동네에 SNS 광고 → "광고요? 못 봤는데." |
| 보통 | 나머지 | 0.7~1.3 (선형) | — |
| 대박 | 5% + 5% × (평균 적합 ≥ 1.2) + 인플루언서·리뷰어 연쇄 3% | 3.0 + 그 품목 유행 3일 | 학생 무리가 SNS 사진 공유 → 줄 서는 가게 |

- 기대보다 손님이 와도 **약속을 못 지키면 역효과**: 품질 메시지인데 그날 신선도 '하' 판매 시 리뷰 −, 가격 메시지인데 품절 시 "낚였다" 불만.
- 광고비는 미디어 계정(전단 인쇄소 주민, 구청 현수막 → 시 계정, SNS·유튜버 → 해당 NPC·미디어 회사)으로 이체된다. 유튜버가 돈을 벌면 그 NPC 생활이 바뀌는 게 보인다.

**효과는 숫자보다 손님 대사로 먼저 듣는다.**
- 전단: "할머니가 이 종이 주던데요, 여기 맞죠?"
- 현수막: "지나가다 현수막 보고 들어왔어요."
- 버스: "버스에서 봤는데 생각보다 가깝네."
- 검색: "지도 앱에서 검색하니까 맨 위에 뜨더라고요."
- SNS: "인스타에서 봤어요! 그 빵 아직 있어요?"
- 유튜버: "○○ 영상 보고 왔어요. 사장님 실물이 더 나으시네."
- TV: "어머, TV에 나온 집이네."
- 후원: "우리 팀 후원하는 데라며? 팔아 줘야지."
- 무반응: (결산 화면) "광고 보고 왔다는 손님: 0명" + 할머니 "광고? 요즘 그런 걸 누가 봐."
- 역풍: "여기 그 사람 광고한 데 아니야? 딴 데 가자."

결산 화면에는 "광고 보고 왔다는 손님 N명(손님층별)"이 나온다. 손님 일부만 출처를 말하므로(40%) 정확한 효과는 회계사·홍보 전문가가 있어야 보인다(정보 비대칭).

### 3.5 전문가

전문가는 이름 있는 NPC다. 고용 경로는 소개(신뢰 필요), 사건 뒤 먼저 연락(세무 통지서 직후 회계사 명함), 인사 앱 공개 모집(C만). 등급 A는 소개로만 — 관계가 문이다.

| 전문가 | 등급 C (신입) | 등급 B (경력) | 등급 A (명성) | 하는 일 | 대표 실수 |
|---|---|---|---|---|---|
| 회계사 | 주 40결, 실수 8%/분기 | 주 120결, 3% | 주 400결, 0.5% | 세금 신고(절세 0/5/10%), 결산 화면에 정확한 광고 효과·매장별 손익, 세무조사 대응 | 신고 누락 → 가산세 20%, 드물게 횡령(C·충성 낮음 0.3%/월: 가게 → 회계사 계정 이체가 장부에 숨어 있다가 감사 때 발견) |
| 변호사 | 계약 1건 30결 | 1건 90결 / 월 고문 300결 | 월 고문 1,000결 | 계약 검토(숨은 조항 발견), 소송, 특허·상표, 법인 분리 조언 | 조항 놓침, 소송 기한 놓침 |
| 노무사 | 월 80결 | 월 200결 | 월 500결 | 근로 계약·해고 절차, 최저시급 정책 대응, 노조·파업 협상 | 부당 해고 판정(보상금 이체), 계약서 누락 |
| 홍보 | 캠페인당 100결 | 월 400결 | 월 1,500결 | 광고 효과 정확한 측정, 역풍 감쇠(−50%/−70%/−85%), 언론 대응, 위기 사과문 | 사과문 역효과, 기자에게 말실수 |
| 컨설턴트 | 보고서 1건 60결 | 200결 | 800결 | 상권 분석 정확도(±20/±10/±4%), 산업 진입 조언(기회 카드 성공 확률 표시), 구조조정 | 그럴듯하게 틀림(확신은 높은데 오차 2배 — 5%) |

- **충성:** 근속 4주마다 실수 확률 ×0.8, 최대 3번. 오래 같이 일한 회계사는 "사장님, 이건 하지 마세요" 먼저 말해 준다(위험 경고 대사).
- **싸면 실수, 비싸면 믿을 만함:** 등급 C를 쓰다 사고가 나면 그 사고가 다음 등급을 소개받는 사건이 된다.

**계약과 숨은 조항.** 모든 계약(임대·공급·납품·투자·고용·광고 모델·인수)은 조항 목록을 가진다.
```ts
interface Clause { id: ClauseKind; visible: boolean; severity: 1|2|3; trigger: Predicate; effect: Effect }
interface Contract { id; kind; parties: [string, string]; clauses: Clause[]; signedDay; reviewedBy?: { expertId; grade } }
```
- 상대방 성격·상황에 따라 숨은 조항 0~3개가 시드로 붙는다(라이벌·악덕 건물주는 더 많이).
- 변호사 검토 시 숨은 조항 하나하나를 등급별 확률로 발견: C 50%, B 80%, A 97%. 발견되면 서명 전 협상(빼 달라 / 대가 받고 수락 / 계약 포기).
- 검토 없이 서명하면 조항은 숨은 채로 남다가 **조건이 맞는 날 효과가 터진다**. 터질 때 "계약서 7조 2항에 따라…" 문자가 오고, 그때 변호사를 찾으면 협상 여지가 조금 남는다(분쟁 비용 별도).

| 숨은 조항 | 효과 | 주로 숨기는 상대 |
|---|---|---|
| 자동 갱신 + 중도 해지 위약금 | 해지 시 남은 기간 임대료 50% 이체 | 건물주 |
| 임대료 연동 인상 | 상권 평판(내가 키운 상권!)이 오르면 임대료 +20% | 건물주 바크(3.6) |
| 원상 복구 | 퇴거 시 인테리어 비용 전액 → 보증금에서 차감 | 건물주 |
| 최소 구매 의무 | 공급처에서 주 N개 이상 안 사면 차액 지불 | 도매상·라이벌 공급 제안 |
| 독점 공급 | 다른 공급처 사용 금지 → 경쟁 공급처의 싼 기회 막힘 | 라이벌 도렌의 공급 자회사 |
| 경업 금지 | 계약 후 1시즌 같은 업종 근처 개업 금지 | 인수 계약·동업 계약 |
| 지분 희석 | 다음 투자 때 내 지분 비율 자동 감소 | 투자자 |
| 지식재산 귀속 | 외주로 만든 결과물(코드·설계)이 고객사 소유 | AI·반도체 설계 외주 고객사 |
| 납기 지연 벌금 | 하루 지연마다 계약액 2% | 대기업 고객사 |
| 손해배상 상한 없음 | 사고 시 피해 전액 | 물류·제약 거래처 |

### 3.6 라이벌 사업가 4명

라이벌은 플레이어와 **같은 규칙**(장부·임대·고용·광고·기회)으로 움직인다. 자기 계정·가게·직원이 있고 돈이 바닥나면 진짜 망한다. 매주 일요일 밤 각자 "행동 규칙 표"를 위에서부터 확인해 하나 이상 실행한다(시드 키 `rival:${id}:${week}`).

**① 도렌 — 확장광 (체인 사장)**
- 성격: 공격적, 숫자만 믿음, 자존심 강함. 말투: 짧고 단정. "골목은 결국 규모가 이깁니다."
- 전략: 잘되는 상권에 바로 옆 매장 개업 → 가격 인하로 점유율 → 공급처 독점 계약.
- 행동 규칙:
  1. 플레이어 가게 주간 매출이 상권 평균의 1.3배 이상 2주 연속 → 100m 안 빈 매물에 같은 업종 개업(7일 뒤).
  2. 같은 상권에서 경쟁 중이면 주력 품목 가격 −15%(3주까지, 그 뒤 현금 30% 미만이면 원상 복구).
  3. 플레이어 공급처에 독점 공급 계약 제안(숨은 조항 2개).
  4. 현금이 시즌 초의 20% 미만 → 가장 약한 매장 폐점, 직원 해고(그 직원들이 구직 시장에 나옴 = 플레이어 기회).
  5. 3번 연속 패배(점유율 하락) → 인수 제안을 받으면 수락 확률 50%.
- 약점: 무리한 확장으로 빚. 금리 인상 사건에 가장 먼저 흔들린다.

**② 세라 — 브랜드 감성가 (카페·패션 창업가)**
- 성격: 사교적, 이미지 중시, 인맥 넓음. 말투: 다정하지만 날카로움. "사람들은 물건이 아니라 이야기를 사요."
- 전략: SNS·인플루언서 광고, 인테리어, **좋은 직원 빼 가기**(시급 +30%, 분위기 좋은 직장).
- 행동 규칙:
  1. 플레이어 직원 중 능력 합 280 이상·사기 50 미만이 있으면 그 직원에게 이직 제안.
  2. 유행 품목이 생기면(대박 광고·리뷰) 3일 안에 비슷한 품목 + 더 예쁜 포장 출시.
  3. 인플루언서·유튜버와 관계가 높아서 플레이어가 같은 유튜버에 광고하면 단가 +50%.
  4. 플레이어와 관계(존중 30 이상)가 좋으면 공동 팝업·콜라보 제안(협력 루트).
  5. 역풍 사건(모델 사고)에 약함: 자기 모델이 사고 치면 한 달 매출 −40%.
- 약점: 원가 관리 허술, 회계 실수.

**③ 바크 — 땅과 정보의 노인 (건물주·도매 거물)**
- 성격: 느긋, 계산적, 정보를 사고판다. 말투: 반말 섞인 옛날식. "장사는 자리가 반이야. 자리는 내가 갖고 있고."
- 전략: 상권이 뜨기 전에 건물 매입, 임대료 연동 조항, 경매에서 플레이어와 경쟁, 소문을 퍼뜨려 가격 조작.
- 행동 규칙:
  1. 상권 평판이 2주 연속 오르는 곳의 매물을 경매·매입(플레이어보다 정보가 1주 빠름).
  2. 자기 건물 세입자 매출이 오르면 다음 갱신 때 임대료 +20%(숨은 조항이 있으면 즉시).
  3. 경매에 플레이어가 참가하면 최고가의 1.1배까지 따라온다. 단, 플레이어가 그의 비밀(소문 3개 중 하나)을 알면 물러선다.
  4. 정책 사건(재개발·규제) 전 소문을 퍼뜨려 플레이어가 헐값에 팔게 유도.
  5. 플레이어가 신뢰 40 이상이면 "정보 거래" 제안 — 상권 미래 정보를 주고 지분이나 호의를 받음(멘토 같은 라이벌).
- 약점: 현금이 아니라 건물로 부자. 금리 상승·부동산 정책 사건에 자산 가치 하락.

**④ 미오 — 천재 창업가 (기술 스타트업)**
- 성격: 호기심, 조급함, 잘 넘어지고 잘 일어남. 말투: 빠르고 들뜸. "이거 되면 세상이 바뀌어요. 진짜로."
- 전략: 산업 기회(AI·바이오·게임)에서 플레이어와 **같은 기회 카드를 두고 경쟁**. 투자자 설득 대결, 인재 영입 경쟁.
- 행동 규칙:
  1. 플레이어가 거절·만료시킨 기회 카드의 1순위 인수자(기회가 사라지지 않고 라이벌에게 간다 — 4.4).
  2. 투자 유치 성공 시 공격적 채용(플레이어가 노리는 인재와 겹치면 영입 경쟁).
  3. 시즌마다 30% 확률로 큰 실패(임상 실패·서비스 장애) → 현금 바닥이면 파산 → 그의 팀·특허가 경매에 나옴.
  4. 파산 뒤에도 사라지지 않음: 2시즌 뒤 재창업, 혹은 플레이어에게 "같이 할래요?" 동업 제안.
  5. 플레이어와 관계(호감·존중 30 이상)면 경쟁 대신 공동 입찰 제안.
- 약점: 돈 관리·법률 약함(숨은 조항에 잘 당함).

라이벌끼리도 싸우고(도렌 대 세라), 그 소식이 뉴스 앱에 뜬다 → 세계가 나 없이도 움직인다.

### 3.7 동업자·멘토

| 인물 | 역할 | 만나는 곳 | 주는 것 | 위험 |
|---|---|---|---|---|
| 누엘 (기존 NPC, 차 배합사) | 첫 동업자 후보 | 이미 아는 이웃 | 공동 투자(신메뉴·두 번째 가게), 공급 할인 | 관계 나빠지면 배합 비법 들고 독립 |
| 아로 (기존 NPC, 빛씨 조율사) | 기술 동업자 | 단골 기회 손님 | 반도체·전자 쪽 작은 문, 기술 장벽 해결 | 회사(빛고리) 이해충돌 — 내부자 정보 문제 |
| 고담 선생 (새 NPC, 은퇴한 무역상) | 멘토 | 재즈바·전시회(돈 쓰는 삶) | 위기 때 조언·소개(등급 A 전문가, 은행장), 재기 기회 | 거의 없음. 단, 무시하면 연락 끊김 |
| 하람 (새 NPC, 젊은 투자자) | 투자자·동업자 | 경매장·스타트업 모임 | 큰 문 자금(지분 대가) | 실적 압박, 경영권 다툼, 배신(라이벌 미오에게 갈아탐) |

**동업 규칙:** 공동 사업은 `entity` 계정 하나를 만들고 출자금을 각자 이체(지분 = 출자 비율, 노력 지분 따로 합의 가능). 이익 배당도 이체. 결정은 지분 과반. 동업자 신뢰가 20 미만으로 떨어지고 그 사람 '야망' 성향이 높으면 시즌마다 배신 굴림(15%): 지분 매각을 라이벌에게, 핵심 직원 데리고 독립, 비밀 누설. 변호사가 동업 계약서에 경업 금지·우선 매수권을 넣어 두면 배신 효과가 반감된다.

**위기 때 도움:** 현금 7일치 미만일 때 신뢰 40 이상 동업자·멘토가 "도와줄까?" — 무이자 대출(그 사람 계정에서 이체)·손님 소개·은행 보증.

### 3.8 원인 있는 도시 사건 (23개)

사건 엔진 = 원인 조건(세계 상태 술어) → 예고 단서(1~3일 전) → 발생 → 결과 → 플레이어 대응 선택. 같은 날 큰 사건은 최대 1개, 작은 사건 2개.

| # | 원인 | 단서(미리 보임) | 결과 | 플레이어 대응 |
|---|---|---|---|---|
| 1 | 날씨 비(지금 `weatherFor`) | 전날 뉴스 일기예보 | 유동 인구 −30%, 차·수프 용인 +25%, 우산 수요 | 우산을 계산대 옆 칸에, 따뜻한 품목 가격 조정 |

사건 데이터:
```ts
interface CityEventDef {
  id: string; size: 'small'|'big';
  cause: (w: WorldView) => number;      // 0이면 안 일어남, 양수면 그날 확률
  leadDays: number; clue: ClueDef;      // 단서는 leadDays 전에 뉴스·대사·지도에 뜬다
  durationDays: number; effects: EffectDef[];
  responses: { id: string; label: string; effects: EffectDef[] }[];
}
```
`cause`는 현재 상태에서 계산하고 굴림은 `rng(seed, "event:" + id + ":" + day)`. 원인이 사라지면 예고된 사건도 취소될 수 있다(단서를 보고 원인을 없애는 플레이가 가능 — 불만을 줄이면 점검이 오지 않는다).

### 3.9 돈 쓰는 삶

원칙: 소비는 **문을 연다.** 각 소비가 여는 것을 사람·기회·컨디션·모임 네 칸으로 적는다. 유지비는 작고, 못 내면 "멈춤"(집은 줄여 이사, 차는 주차장에, 회원권은 정지)이지 몰수가 아니다.

**컨디션(0~100)과 삶의 만족(0~100).**
- 컨디션: 잠·식사·운동·과로. 높으면 손 운영 속도 +10%, 발표·협상 성공 +5%. 30 미만이면 실수(계산 실수·말실수) 확률 +, 결정 카드 중 하나가 "피곤해서 잘 모르겠다"(선택지 하나 가려짐).
- 삶의 만족: 문화·집·관계·성취의 합. 높으면 멘토·동업자 관계 상승 속도 +, 위기 때 회복 빠름. 게임 목표 화면의 숫자 중 하나(돈만이 점수가 아니다).

| 소비 | 단계·가격 초안 | 사람 | 기회 | 컨디션 | 모임·지위 |
|---|---|---|---|---|---|
| **집** | 원룸(월 150) → 상점가 투룸(월 400) → 강변 아파트(월 1,500) → 언덕 주택(매입 8만~) → 펜트하우스(매입 50만~) | 사는 동네의 이웃이 바뀐다(상점가 = 가게 사장들, 강변 = 직장인·연구원, 언덕 = 부유층·투자자) | 이웃에게서 오는 기회 카드 풀이 바뀜, 집 초대(지금 `inviteHomeTea`) 가능 | 출근 거리(가게까지 이동 시간), 방 분위기(지금 `atmosphere`) → 아침 컨디션 + | 주소가 모임 초대 조건 중 하나 |
| **문화: 맛집** | 동네 식당 15 → 고급 레스토랑 200 | 식당 사장·단골 손님(다른 업종 사장들) | 외식 산업 작은 문(레시피·셰프 소개) | +10 | 미식 모임 |
| **문화: 공연·재즈바** | 회당 30~300 | 멘토 고담 선생, 예술가, 투자자 하람 | 미디어·엔터 기회, 후원 광고 | +15 | 후원자 모임 |
| **문화: 전시** | 회당 20~100 | 작가·수집가 | 수집품 경매 정보, 브랜드 콜라보 | +10 | 수집가 모임 |
| **문화: 운동** | 헬스 월 60 / 골프 회원권 시즌 3,000 | 헬스장 = 직장인·경찰·공무원, 골프 = 기업 임원 | 골프 = B2B 고객사 담당자 관계 | 헬스 = 컨디션 상한 +10 | 골프 = 임원 모임(세계 단계 입찰 관계) |
| **문화: 여행** | 국내 500 / 해외 3,000 | 해외 사업가·공급업체 | 수입 품목·해외 공급망 기회, 세계 단계 첫 문 | 다녀오면 +30 (그동안 가게는 직원) | 여행 사진 = SNS 지위 |
| **차** | 경차 2,000 → 승합차 6,000 → 세단 3만 → 수입차 15만 | 차 동호회, 대리점 영업사원 | 경차 = 운반 용량(3.1), 승합차 = 배달 사업 작은 문 | 이동 시간 −40% | 고급차 = 부유층 손님·투자자 첫인상 + |
| **옷** | 지금 `items` 의상 + 정장 300 + 맞춤 2,000 | — | 발표·협상·면접(인재 영입) 첫인상 + (지금 `appearance`) | — | 드레스코드 모임 입장 |
| **수집품** | 그림·시계·피규어 100~수만 | 수집가 | 가치가 시드 기반으로 오르내림(투자), 경매에서 라이벌 바크와 만남 | +5 | 수집가 모임 |
| **기부·후원** | 동네 행사 50~ / 장학금 / 구단 후원 | 수혜자·구청 직원·기자 | 공공 입찰 기회, 지역 평판 | 삶의 만족 + | 지역 유지 모임, 표창 |

**지위와 모임:** 모임은 "돈이 얼마 이상" 조건이 아니라 **초대**로 들어간다. 초대 조건 = 이미 그 모임 회원과의 관계 + 주소·차·옷 같은 신호 중 둘 + 평판. 모임마다 주 1회 만남 → 그 자리에서 고급 기회 카드·멘토·투자자를 만난다. 예: 사업가 조찬 모임(상점가 투룸 이상 + 사장 신뢰 30 이상 회원 1명), 후원자 모임(공연 3회 + 기부 1회), 임원 골프(골프 회원권 + B2B 고객사 담당자 존중 30).

모든 소비 대금은 판매자 NPC·사업체 계정으로 이체된다. 플레이어가 자주 가는 재즈바는 매출이 늘어 사장이 2호점을 내고, 그 사장이 동업을 제안할 수도 있다.

### 3.10 세금·은행

- **세금:** 주간 매출의 8%(부가세 성격) + 시즌 이익의 15%(소득세 성격). 가게 → `city` 계정 이체. 시는 이 돈으로 도로 공사(사건 2), 축제(사건 7), 공공 입찰(기회), 보조금(정책)을 집행한다 → 세금이 도시 사건과 기회로 돌아오는 순환.
- **은행:** `bank` 계정(세계 생성 때 1회 자금). 대출 = 은행 → 플레이어 이체, 이자·원금 = 플레이어 → 은행. 예금 이자 = 은행 → 예금자. 은행 잔액이 바닥나면 대출이 막히고 금리가 오른다(돈 보존이 금리를 만든다).
- **대출 조건은 숫자 잔액이 아니라 신용:** 실적 기록(주간 보고 4주 이상), 담보(보증금·건물·설비), 보증인(멘토·동업자 신뢰 40), 회계사 등급. 대출 한도 = 최근 4주 평균 순이익 × 8 + 담보 가치 × 0.6.

### 3.11 계정 지도 (돈 보존)

| 계정 | 처음 자금 | 들어오는 돈 | 나가는 돈 |
|---|---|---|---|
| `player` | 600 (새 게임) / 지금 잔액(기존) | 매출 정산·배당·급여·대출 | 원가·임대·급여·광고·전문가·소비·세금 |
| 주민 개인 계정 | 지금 그대로(1,000 또는 할당) | 급여·판매 | 구매 |
| `crowd:<층>` 6개 | 각 20만 | `outside`의 임금 이체(이 층 사람들이 '다른 곳에서 번 돈', 하루 정해진 양) | 이름 없는 손님 구매 |
| `outside` (도시 밖 경제) | 10¹² | 수입 대금·관광 손님 지출의 원천 회수, 수출·해외 고객사 대금 지급 | `crowd` 임금, 수출 대금 |
| `city` (시) | 100만 | 세금·과태료·임대(공공 현수막) | 공공 입찰 대금·보조금·공사 대금 |
| `bank` | 1,000만 | 이자·상환 | 대출·예금 이자 |
| `media:*`, `courier`, 전문가·라이벌 개인 계정 | 0~시드 | 광고비·배달비·보수 | 그들의 소비 |
| `entity:*` (법인·동업) | 0 | 출자·매출·투자 | 비용·배당 |

- **새 돈은 세계 생성(또는 세이브 이전) 때 한 번만.** 그 합계를 `ledger.supply`에 기록하고, 테스트가 매일 `Σ balances === supply`를 확인한다. 지금 코드의 `??= 1000`·`initial:` 할당도 같은 범주라서 이전 코드에서 supply에 합산한다.
- `crowd`에서 손님 지출이 바닥나면 그 층 손님은 덜 산다(불황이 장부에서 생긴다). `outside`는 크고 느리게 움직이는 바다다 — 이 덕분에 세계 단계 규모(수억 결)까지 같은 장부로 간다(`Number.MAX_SAFE_INTEGER` ≈ 9×10¹⁵ 안).

## 4. 기회 시스템

### 4.1 규칙
1. **돈 해금 절대 금지.** 기회 카드의 요구 조건에 '잔액 ≥ N'은 넣을 수 없다(데이터 검사 테스트로 막는다).
2. 기회는 세계 안의 누군가·무언가가 **건넨다**. 카드에는 항상 "누가, 왜 지금"이 있다.
3. 비용은 있지만 **조달 방법이 여러 개**다: 내 돈 / 동업자 출자 / 투자자 / 대출 / 고객사 선금 / 작게 시작(작은 문). 돈이 많으면 빨리·크게, 적으면 천천히·작게.
4. 진짜 장벽은 비현금 요구 조건: 사람(인재·신뢰), 허가, 기술, 거래처, 투자자 설득, 평판, 정보.
5. **놓친 기회는 사라지지 않고 누군가에게 간다**(라이벌·동업자·직원). 뉴스로 결과가 보인다 — "미오, 연구원 ○○와 손잡고 진단 키트 개발" — 인과가 보이고 아쉬움이 다음 판단을 만든다.
6. 동시에 열린 기회 카드는 3장까지(폰 피로). 하나를 고르면 다른 하나가 닫힐 수 있다(시간·사람이 겹치면).

### 4.2 기회의 원천 6가지
| 원천 | 예 | 생성 조건(예) |
|---|---|---|
| 손님 | 단골 연구원 "투자자를 찾아요", 큰손 "회사 행사 다과 납품" | 단골 + 직업 + 신뢰 20 + 대화 선택 |
| 관계 | 누엘 "같이 두 번째 가게 낼래?", 멘토 "이 사람 만나 봐" | bonds 축 조건 + 시즌 |
| 뉴스 | "정부, 반도체 소재 국산화 보조금", "제약사 특허 만료 목록" | 정책·시장 사건 |
| 경매 | 파산한 공장 설비, 미오 팀의 특허, 건물 | 라이벌 파산·은행 압류·시 매각 |
| 놀러 간 곳 | 재즈바에서 만난 음반사 대표, 골프장의 물류 회사 임원 | 돈 쓰는 삶 장소 + 그 장소의 NPC 풀 |
| 직원 | 즉흥 발명형 알바 "신메뉴 아이디어", 점장 "옆 동네 상권 좋아요", 첫 알바 독립 | 직원 성향 + 근속 |

### 4.3 기회 카드 데이터 구조
```ts
interface OpportunityDef {               // data/opportunities.ts (정적)
  id: string; industryId: IndustryId; door: 'small'|'big'|'side';
  source: 'customer'|'relation'|'news'|'auction'|'outing'|'staff';
  giverRole: string;                     // '단골 연구원', '물류 회사 임원'…
  trigger: TriggerExpr;                  // 세계 상태 술어(데이터로 표현, 아래)
  pitch: string[];                       // 건네는 사람 대사 2~3줄 (원형 말투로 변형)
  requirements: Requirement[];           // 비현금만
  cost: { upfront: number; weekly: number; financing: FinanceOption[] };
  speedUps: SpeedUp[];                   // 돈으로 살 수 있는 '속도'
  lifetimeDays: [number, number];
  onAccept: EffectDef[]; onDecline: EffectDef[]; onExpire: EffectDef[];  // 만료 = 라이벌 이전 등
  next?: string[];                       // 이어지는 기회(작은 문 → 큰 문)
}
type Requirement =
  | { kind: 'bond'; who: string; axis: Axis; min: number }
  | { kind: 'talent'; role: string; count: number }       // 그 역할의 사람을 고용·영입해야
  | { kind: 'permit'; id: string }                         // 허가 절차(시간·서류·전문가)
  | { kind: 'tech'; id: string; level: number }            // 연구로만
  | { kind: 'client'; id: string }                         // 거래처 확보(발표·관계)
  | { kind: 'investor'; pitchScore: number }               // 투자 설득 미니게임 점수
  | { kind: 'reputation'; area: string; min: number }
  | { kind: 'knowledge'; id: string };                     // 정보(조사·소문·전문가)
interface OpportunityCard {               // 세이브에 들어가는 동적 상태
  id: string; defId: string; giverId: string; createdDay: number; expiresDay: number;
  state: 'offered'|'accepted'|'declined'|'expired'|'taken'; takenBy?: string;
  met: Record<number, boolean>;           // 요구 조건별 충족 여부(조사 전엔 '모름')
}
type TriggerExpr = { all?: TriggerExpr[]; any?: TriggerExpr[] } | { fact: FactId; op: '>='|'<='|'=='; value: number | string };
```
- `TriggerExpr`는 함수가 아니라 **데이터**다 → 세이브 안전, Codex가 대량 작성 가능, 테스트로 "잔액 사실(fact: 'cash')은 트리거·요구 조건에 쓰지 못함"을 검사.
- 생성: 매일 아침 모든 정의의 트리거를 평가 → 참인 것 중 `rng(seed, "opp:" + defId + ":" + day)`로 하루 최대 1장(시즌 큰 기회는 시즌 리뷰 때). 같은 정의는 쿨다운 14일.
- 카드는 결폰 메시지 앱에 **건넨 사람의 메시지**로 도착한다(지금 메신저의 말투·지연 규칙 사용). 손님·놀러 간 곳에서 생긴 카드는 그 자리 대화로 먼저 보이고, 메시지 앱에 기록된다.

### 4.4 진행과 결과
- 수락하면 '프로젝트'가 된다: 요구 조건을 하나씩 채우는 체크리스트(사람 찾기 → 허가 → 첫 거래). 각 단계는 다른 시스템(인사·전문가·관계·발표)을 쓴다.
- **돈은 속도만**: `speedUps` 예 — 헤드헌터(인재 찾기 7일 → 2일, 비용), 컨설턴트(허가 서류 실수 확률 ↓, 기간 −30%), 새 설비(수율 학습 곡선 출발점 ↑), 두 번째 시도 비용(실패 후 재시도). 어떤 speedUp도 요구 조건 자체를 지우지 않는다.
- 거절: 건넨 사람 관계 소폭 하락(−2) 대신 "다음에 또 말해 줘요" 선택지로 쿨다운 단축.
- 만료·거절된 기회는 `onExpire` 규칙에 따라 라이벌(미오 1순위, 업종이 맞으면 도렌·세라·바크)이나 직원·동업자에게 간다. 그 사람이 성공·실패하는 결과가 2~4주 뒤 뉴스로 나온다.

### 4.5 산업 공통 뼈대를 데이터로
```ts
interface IndustryDef {                   // data/industries.ts
  id: IndustryId; name: string;
  doors: { small: VentureTemplate; big: VentureTemplate };
  roles: RoleDef[];                       // 인재: 역할·희소성·시장 시급
  research: ResearchDef[];                // 연구: 단계·기간·성공 확률·필요 역할
  production: { unitCost: number; capacityPerWeek: number; leadDays: number; qualityFrom: StatRef[] };
  sales: { channels: ('retail'|'b2b'|'bid'|'license'|'subscription')[]; demandCurve: CurveRef };
  competition: { rivals: string[]; global: string[] };
  unique: UniqueRuleId;                   // 코드 훅 하나: 'yield'|'trial'|'gpu'|'hit'|'route'|…
  barriers: Requirement[];                // 큰 문의 비현금 장벽
}
interface Venture {                       // 세이브: 플레이어·라이벌이 가진 사업 하나
  id: string; industryId: IndustryId; entityAccount: string; door: 'small'|'big';
  staff: string[]; tech: Record<string, number>; capacity: number; quality: number;
  pipeline: { researchId: string; progress: number; startedDay: number }[];
  contracts: string[]; uniqueState: Record<string, number>;   // 고유 규칙 상태(수율·임상 단계 등)
}
```
매주 `tickVenture(v, world)` 하나가 공통 순서로 돈다: 인재(급여 이체·사기) → 연구(진행·성공 굴림) → 생산(용량·품질) → 판매(채널별 수요·계약 납품 → 매출 이체) → 경쟁(라이벌 점유율) → `unique` 훅. 고유 훅만 산업별 작은 순수 함수(각 ≤ 60줄)다.

### 4.6 산업 14개 (지금 가게의 확장인 소매 체인은 2.3·5.2에서 다룸)

**1. 외식 (식당·케이터링)**
- 작은 문: 사무실 다과 정기 납품, 푸드트럭 / 큰 문: 프랜차이즈 본사(가맹점 모집)
- 고유 재미: **레시피와 셰프** — 메뉴 개발(재료 조합 실험, 손님 반응 데이터)과 셰프의 기분이 맛을 바꾼다.
- 진짜 장벽: 셰프 인재, 위생 허가, 가맹점주 신뢰
- 첫 기회 예: 큰손 손님이 "다음 주 회사 창립 행사에 다과 200인분 되나요?" — 하루 생산 용량을 넘으니 누엘과 동업하거나 거절해야 한다.

**2. 물류·배달**
- 작은 문: 승합차 한 대로 동네 배달 대행 / 큰 문: 도시 물류 센터와 노선망
- 고유 재미: **노선 퍼즐** — 지도에 경유지를 이어 시간·기름·약속 시간을 맞춘다(폰에서 점 잇기).
- 장벽: 기사 인재, 화물 허가, 대형 화주 계약
- 첫 기회 예: 도시락 가게 사장(단골)이 "배달 플랫폼 수수료 올라서 죽겠어요, 사장님 차로 같이 돌면 안 돼요?"(사건 16 뒤)

**3. 부동산**
- 작은 문: 내 가게 건물 한 층 매입·전대 / 큰 문: 상권 개발(빈 거리 재생)
- 고유 재미: **상권을 내가 만든다** — 매력 있는 세입자를 골라 넣으면 거리 유동 인구가 오른다(세입자 조합 보너스).
- 장벽: 은행 신용, 건축 허가, 바크와의 정보 싸움
- 첫 기회 예: 수다쟁이 할머니 "저 건물 주인이 급하게 판대. 아들 빚 때문에." — 경매 전에 직접 찾아가면 협상 기회.

**4. 패션**
- 작은 문: 동네 수선·리폼 + 온라인 판매 / 큰 문: 자체 브랜드 + 시즌 컬렉션
- 고유 재미: **유행 예측** — 시즌 유행 색·형태가 뉴스·SNS·거리 사람 옷차림 단서로 미리 보인다. 맞히면 대박, 틀리면 재고 산.
- 장벽: 디자이너 인재, 봉제 공장 거래처, 브랜드 평판
- 첫 기회 예: 세라 가게에서 빼 간… 아니, 세라가 내보낸 디자이너가 "제 디자인 알아봐 준 건 사장님뿐이에요."

**5. 뷰티·화장품**
- 작은 문: 소분 판매·로드숍 / 큰 문: 자체 처방 화장품(연구·허가)
- 고유 재미: **성분 조합과 입소문** — 처방 연구 결과와 리뷰어(3.2 ⑧) 반응이 연결.
- 장벽: 화학 연구원, 제조 허가, 인플루언서 신뢰
- 첫 기회 예: 학생 무리가 매일 사 가는 립밤을 보고 연구원 단골이 "이거 성분 좀 바꾸면 더 팔리겠는데요?"

**6. 게임**
- 작은 문: 2인 외주 개발(남의 게임 일부) / 큰 문: 자체 IP 게임 출시
- 고유 재미: **흥행 복권과 출시 타이밍** — 완성도·트렌드·출시 주 경쟁작이 흥행 확률을 만든다. 출시 날짜를 직접 고르는 긴장.
- 장벽: 개발자 인재, 퍼블리셔 계약(지식재산 귀속 조항!), 팬덤
- 첫 기회 예: 단골 학생 무리 중 한 명이 "저희 팀 게임 데모 있는데, 사장님 가게에 시연대 하나 놔도 돼요?"

**7. 미디어·엔터**
- 작은 문: 동네 유튜브 채널(내 가게 이야기) / 큰 문: 기획사·제작사
- 고유 재미: **화제성 파도** — 사건·논란을 콘텐츠로 바꾸는 속도. 광고 시스템을 거꾸로(광고를 받는 쪽) 경험.
- 장벽: 크리에이터 인재, 방송 채널 관계, 스캔들 관리(홍보 전문가)
- 첫 기회 예: 재즈바에서 만난 음반사 대표 "사장님 가게 배경으로 뮤직비디오 찍어도 될까요? 대신…"

**8. 반도체**
- 작은 문: 부품 유통(아로의 소개로 조율 부품 소분 판매), 칩 설계 외주 / 큰 문: 팹(공장)·패키징 라인
- 고유 재미: **수율·설비·호불황** — `수율 = 기본 × (1 − e^(−학습/τ)) × 설비 등급 × 청정도`. 학습은 라인 가동 주수, τ = 8주(설비 A면 5주). 업계 경기는 4시즌 주기 사인파 + 시드 소음, 호황에 증설하면 불황에 재고 폭탄.
- 장벽: 공정 엔지니어(희소), 설비 공급사 거래(해외), 대형 고객사 인증, 보조금 정책
- 첫 기회 예: 단골 아로가 "회사에서 남는 부품 재고를 소분해 줄 데가 없대요. 사장님 가게 창고 비어 있죠?" — 소분 유통이 첫 매출, 그 과정에서 고객사 엔지니어를 알게 된다.

**9. 제약**
- 작은 문: 약국·복제약 유통 / 큰 문: 신약 개발
- 고유 재미: **임상 확률·허가·특허 만료** — 1상 60% → 2상 35% → 3상 60% → 허가 85%. 단계마다 기간(4~12주)과 비용. 특허 만료 달력이 공개돼 복제약 진입 타이밍 싸움(만료 후 원가 −70%, 첫 진입자 독점 4주).
- 장벽: 약사·연구원, 허가 기관, 임상 병원 관계, 투자자(긴 적자)
- 첫 기회 예: 뉴스 "○○ 진통제 특허 다음 시즌 만료" + 단골 약사 "제가 유통 허가가 있어요, 같이 해 볼래요?"

**10. 바이오 (진단·배양)**
- 작은 문: 진단 키트 수입 유통 / 큰 문: 배양육·진단 장비 개발
- 고유 재미: **실험 배치의 운과 오염** — 배치 성공률이 청결·연구원 눈 능력·장비에 따라 달라지고, 오염은 연쇄(같은 실험실 다른 배치도 위험).
- 장벽: 연구원, 실험실(허가), 병원·식품 기업 거래처
- 첫 기회 예: 감염병 유행 사건(17) 중 연구원 단골 "키트는 있는데 유통할 데가 없어요."

**11. AI**
- 작은 문: 2인 외주(챗봇·데이터 라벨링) / 큰 문: 자체 모델·서비스
- 고유 재미: **인재·GPU·데이터·경쟁 모델** — `모델 점수 = 인재 합^0.5 × GPU^0.3 × 데이터 품질 × 연구 진행`. 경쟁 모델(라이벌 미오·해외 거대 기업) 출시 때마다 시장 기준 점수가 올라 내 모델 가치가 깎인다. GPU는 공급 부족 사건(반도체 산업과 연결)에 휘둘린다.
- 장벽: 연구자(가장 희소, 미오와 영입 경쟁), GPU 공급 계약, 데이터 권리(변호사), 투자자
- 첫 기회 예: 가게 결제 기록을 본 데이터 전공 알바생 "사장님, 이걸로 재고 예측 프로그램 만들어 볼게요. 친구 한 명만 더 데려와도 돼요?"

**12. 에너지**
- 작은 문: 건물 옥상 태양광 설치 대행 / 큰 문: 발전 단지·전력 판매
- 고유 재미: **날씨와 정책** — 일조량(날씨 시드)이 발전량, 보조금·전력 단가 정책이 수익을 바꾼다. 정전 사건(12)의 원인 쪽을 쥐는 재미.
- 장벽: 전기 기술자 면허, 인허가, 주민 동의(관계!)
- 첫 기회 예: 정전 다음 날 건물주 바크가 "옥상 놀리는데 태양광 할 사람 없나?" — 라이벌이 거래처가 되는 순간.

**13. 건설**
- 작은 문: 가게 인테리어 시공팀 / 큰 문: 공공 입찰 건물·도로
- 고유 재미: **공정표와 날씨 지연** — 비 오는 날 공정 정지, 납기 지연 벌금 조항.
- 장벽: 현장 소장 인재, 건설 면허, 시 공무원 관계(부패 유혹 이벤트 — 받으면 큰 위험)
- 첫 기회 예: 내 가게 인테리어를 해 준 목수 NPC가 "일감이 넘쳐서 혼자선 못 해요. 팀 꾸릴 돈 대 주면 반반 할래요?"

**14. 금융·투자**
- 작은 문: 동네 사장님들 공동 구매 계모임 운영 / 큰 문: 투자사(라이벌 회사 지분 매입·스타트업 투자)
- 고유 재미: **정보와 타이밍** — 정보 비대칭(7.6)이 가장 큰 무기, 내부자 정보는 수사 위험.
- 장벽: 금융 허가, 투자자 신뢰(운용 실적), 애널리스트 인재
- 첫 기회 예: 사업가 조찬 모임에서 "사장님은 돈을 잘 굴리시던데, 우리 돈도 좀 맡아 줘요."

## 5. 무대 확장

### 5.1 동네 — 상권 분석
상권 지표는 **실제 시뮬레이션에서 나온다**(주민 일과·손님층 계정·라이벌 가게). 숫자를 지어내지 않는다.

| 지표 | 계산 | 보이는 방법 |
|---|---|---|
| 유동 인구 | 시간대별 그 거리 칸을 지나는 주민 수(일과) + 이름 없는 손님 흐름(상권 층 비중 × 시간 곡선) | 지도 앱 거리 색(따뜻한 색 = 많음), 시간 슬라이더 |
| 손님층 | 6층 비중 | 매물 카드의 작은 막대 6개 |
| 주변 가게 | 반경 200m 가게 목록: 경쟁(같은 업종, 손님 −) / 보완(카페 옆 빵집, 손님 +) | 지도 핀 + "경쟁 2 · 보완 3" |
| 월세 | 상권 평판·유동 인구·건물주 성격에서 결정 | 매물 카드 |
| 주차 | 칸 수, 공사 예정 | 아이콘 |
| 미래 단서 | 재개발 소문·학교 이전·라이벌 매입 | 정보 확보 정도에 따라 "?" 또는 내용 |

- 정확도: 소문만 들음 ±40%, 직접 가서 1시간 관찰(실제 30초 손 운영 모드처럼 사람 세기) ±15%, 컨설턴트 등급별 ±20/±10/±4%. 화면에 "추정 52명/시 (±15%)"처럼 오차를 함께 보여 준다.
- 매물 선택 = 부동산 앱에서 매물 카드를 넘겨 보고, 끌리면 **직접 가 보기**(지도에서 길 안내 → 그 거리에 도착하면 지표가 정확해지고 건물주와 대화).

### 5.2 도시
- 동네 4~6개로 된 도시 지도. 각 동네는 성격이 있다: 상점가(지금 골목), 오피스 거리, 대학가, 강변 주거, 언덕 부촌, 항구·물류 단지, 공단.
- 지점 관리: 지도에서 내 매장 핀을 탭 → 점장 보고 3줄 + 결정 카드. 점장이 해결 못 한 일만 올라온다(원칙 1).
- 물류: 도시 단계부터 창고 하나를 두면 매장 공급을 묶어서 처리(배달비 −50%). 창고 위치가 노선 퍼즐(산업 3)과 이어진다.
- 라이벌 영역: 지도에 라이벌 가게 색이 칠해진다. 동네별 점유율 막대. "이 동네는 도렌 천하" 같은 한 줄.
- 직접 방문: 커져도 플레이어는 걸어서·차로 간다. 공장 라인을 직접 걸으면 문제 원인 하나 발견(3.1), 고객사에 직접 가면 담당자 관계 + 입찰 가산점.

### 5.3 세계
- **세계 지도는 도시 5개 핀**으로 단순하게(가상 국가·가상 도시명). 각 도시: 산업 강점, 환율, 규제 성향, 글로벌 경쟁사 본거지.
- **글로벌 경쟁사 3개**: 반도체·AI 거인(장벽이 높은 산업의 기준 점수를 끌어올림), 소비재 공룡(가격 공세), 물류·원자재 상사(공급망 쥠). 이들은 이름 있는 임원 NPC를 가진다(관계 대상).
- **고객사 입찰** (세계 단계 핵심 루프):
  1. 입찰 공고(뉴스·메시지) — 요구: 가격·품질·납기·레퍼런스·현지 생산.
  2. 제안서 구성(폰 한 화면): 가격 슬라이더, 납기 약속(지연 벌금 조항 위험), 품질 등급, 현지 파트너 선택. 각 항목이 점수와 위험을 바꾼다.
  3. **발표**(직접 무대에 섬): 상대 임원 3명의 성격(원형) 단서를 미리 조사할 수 있다. 질문 3개가 나오고 답 선택지 3개 중 그 임원 성격에 맞는 답이 가산점. 컨디션·옷(첫인상)·골프 관계가 보정.
  4. 결과: 점수 비교(경쟁사 점수는 정보 수준에 따라 '모름'/'대략'/'정확'). 낙찰 시 장기 계약(숨은 조항 검토!).
- **공급망**: 원자재 3종(금속·화학·농산), 각 산지 도시 2곳. 항구 파업·환율·관세 사건이 납기·원가를 흔든다. 플레이어는 "한 곳에 몰기(싸지만 위험) vs 나누기(비싸지만 안전)"와 재고 일수를 정한다.

### 5.4 폰 화면에서의 모양
- 동네는 3D 거리 걷기가 기본(지금 그대로), 결폰 지도 앱은 같은 동네의 2D 일러스트 지도. 도시·세계 단계에선 지도 앱 위에 단계 버튼(동네/도시/세계)이 생기고, 핀 탭 → 이동(시간 소모, 컷 전환) → 3D 현장.
- 해외 출장은 여행처럼 며칠이 들고, 그동안 국내는 자회사 대표들이 운영(그들 사건이 메시지로 옴).
- 한 손 엄지 조작: 두 손가락 확대 대신 단계 버튼 + 한 손가락 끌기, 핀 최소 44pt, 시간 슬라이더는 하단.

## 6. 결폰 앱 구성

홈 화면 = 앱 9개 + 위젯 하나 "오늘 결정할 것 N"(가장 급한 3개). 앱은 돈으로 해금하지 않는다. 처음부터 있는 앱 5개(메시지·은행·뉴스·지도·인사), 나머지는 **누군가 깔아 줄 때** 생긴다(광고 = 인쇄소 사장이 "요즘 다 앱으로 해요", 주식 = 첫 월급 받은 알바생이 추천, 부동산 = 첫 매물 문의 때, SNS = 학생 무리가 가게 사진 올렸다고 알려 줄 때).

| 앱 | 첫 화면 | 핵심 조작 | 알림 규칙 |
|---|---|---|---|
| **메시지** | 대화 목록. 기회 카드는 건넨 사람 대화 안에 카드 말풍선으로 | 카드 열기 → 요구 조건 체크리스트 → 수락/나중에/거절 | 기회·직원 사직·계약 사건만 푸시 |
| **은행** | 잔액·이번 주 들어옴/나감 막대, 대출·예금 | 대출 신청(신용 화면), 이체, 저축 예약(지금 `reserve`) | 상환일 전날 |
| **뉴스** | 오늘 헤드라인 3개 + 업계 소식(라이벌) + 날씨·정책 | 기사 탭 → 관련 장소·회사로 이동 링크 | 큰 사건 예고만 |
| **지도** | 동네/도시/세계 단계, 상권 색, 내 가게·라이벌 핀 | 매물·장소 탭, 길 안내, 시간 슬라이더 | 없음 |
| **부동산** | 매물 카드 넘기기(손님층·월세·주변 가게·오차) | 직접 가 보기, 계약(변호사 검토 버튼), 경매 입찰 | 관심 매물 변동 |

## 7. 상장·주주·인수·파산·거시경제·정보

### 7.1 상장
- 조건(비현금): 법인(`entity`) 3시즌 이상 흑자, 회계사 등급 B 이상 + 외부 감사 통과(감사 때 숨은 횡령·실수가 드러남), 변호사, 주관사(은행 NPC) 관계 신뢰 30. 기회 카드 "주관사 담당자가 상장 이야기를 꺼냄"으로 시작.
- 공모: 지분 20~30%를 투자자 계정들(`fund:*`, 세계 생성 때 자금)에 판다 → 그 돈이 법인 계정으로 이체. 공모가 = 최근 이익 × 업종 배수 × 발표 점수 보정.
- 상장 뒤 주가는 지금 `market.ts` 규칙(소음 + 사건 + 매출 변화)을 그대로 따른다: 내 회사의 주간 매출 변화가 `recordNpcRevenue`처럼 주가에 들어간다.

### 7.2 주주
- 시즌마다 주주총회(폰 화면 하나): 목표 제시(매출·이익·신사업) → 다음 시즌 실적과 비교.
- 목표 미달 2시즌 연속 + 플레이어 지분 50% 미만 → 해임 안건. 표결 = 주주별 성향(단기 이익형·장기 성장형·라이벌 지분). 해임되면 그 회사는 떠나고(지분은 남음), 플레이어는 개인 자산·사람·평판으로 다음 판을 시작한다(파산과 같은 재기 루트).
- 배당은 법인 → 주주 계정 이체. 라이벌 바크·투자자 하람이 지분을 모으면 이사회 의석 요구.

### 7.3 인수
- 라이벌 가게·회사를 산다: 비상장 = 직접 협상(그 라이벌 성격·현금 상황이 수락 확률), 상장 = 주식 매집(지분 30% 넘으면 공개 매수 의무 — 단순화).
- 피인수: 플레이어 회사가 상장했고 주가가 낮으면 라이벌·글로벌 경쟁사가 매집. 방어 = 우호 주주(동업자·멘토)·실적 발표·백기사 기회 카드.
- 인수 후 통합: 인수한 회사 직원 사기 −20, 문화 충돌 사건, 경업 금지 조항 확인.

### 7.4 파산과 재기
- 파산 조건: 법인 계정이 2주 연속 지급 불능(임대·급여·이자). 지금 `Lease`의 연체 3일 폐업을 법인 단위로 확장.
- 청산: 자산(설비·재고·건물)을 경매에 → 대금이 채권자(은행·직원 미지급 급여·거래처)에게 순서대로 이체. 모자라면 채권자가 손해를 본다(돈 생성 없음, 손실은 그냥 덜 받는 것).
- **법인 분리:** 변호사 조언으로 개인과 법인을 나눠 뒀으면 개인 계정·집은 지켜진다. 개인 보증을 섰으면 개인 자산도 청산 대상(보증 조항!).
- **재기:** 사람(bonds)과 평판의 '성실' 부분은 남는다. 파산 후 7일 안에 신뢰 40 이상인 멘토·동업자·전 직원이 기회 카드를 준다("다시 해 봐요, 제가 작은 가게 하나 내드릴게요"). 실패 경험은 '노련함' 표식 → 같은 산업 재진입 시 숨은 위험 하나를 미리 본다. 첫 알바생이 대표가 된 자회사가 살아 있다면 그가 손을 내민다(서사 회수).

### 7.5 금리·환율·정책
- **금리:** 시즌마다 기준금리 발표(0.5~6%). 변화 = 은행 잔액 상황(대출이 많아 은행 현금이 줄면 인상 압력) + 물가(최근 평균 판매가 변화) + 시드 소음. 대출 이자율 = 기준 + 신용 가산(1~6%). 영향: 라이벌 도렌(빚 많음)·바크(부동산) 흔들림, 매물 가격, 예금 이자.
- **환율:** 세계 도시 통화 5개 대 결. 주간 랜덤 워크 + 사건(항구 파업, 금리 차). 수출 대금·수입 원가·관광객 수(3.2 ⑪)에 곱해진다. `outside` 계정과의 이체 금액에만 적용 → 장부는 결 하나로 유지.
- **정책:** 시즌마다 정책 카드 1~2개(뉴스 2주 예고): 최저시급 인상, 배달 수수료 상한, 반도체 보조금(시 계정이 지급 — 세금이 쌓여 있어야 가능), 플라스틱 규제(포장 원가 +), 재개발 지정, 감염병 방역. 정책은 원인이 있다: 시 계정 잔액, 여론(평판·사건 누적), 산업 동향.

### 7.6 정보 비대칭
- 세계에는 플레이어가 **아직 모르는 사실**이 있다. 각 사실은 `knowledge` 상태(모름 / 소문 / 확인됨)를 가진다: 라이벌 현금 사정, 건물 재개발, 기회 카드의 숨은 위험, 경쟁사 입찰가, 주가 사건(지금 `market.hints`).
- 얻는 방법: 손님·이웃 대화(소문, 정확도 60~80%), 직접 가서 보기(확인), 컨설턴트·변호사(등급별 정확도), 라이벌과의 관계(바크 정보 거래), 직원(전 직장이 라이벌이면 내부 사정).
- **내부자 정보의 위험:** 지금 M2-05 '주가 전조 단서'를 그대로 쓰되, 확인된 내부자 정보로 큰 거래(보유 현금 30% 이상)를 하면 시즌마다 금융 당국 조사 확률 10%. 걸리면 벌금(→ 시 계정) + 평판 −20 + 정보 준 NPC 관계 손상. 정보는 무기이자 유혹이다.

## 9. 위험과 막는 장치

### 9.1 지루함 (반복 노동)
- **위험:** 계산 탭이 3일째부터 지루해진다.
- **장치:** (1) 손 운영 보상 곡선 — 처음엔 사장이 직접 해야 하지만(직원 없음), 첫 알바 뒤에는 손 운영이 "선택"이 되고 대신 단골 2배·추천 성공률 같은 사장만의 보너스로 남는다. (2) 손님 유형이 날마다 섞이고 상권·사건이 비중을 바꾼다. (3) 같은 대사 반복 금지(최근 50줄 기록, 같은 줄 하루 1회). (4) 직원이 생기면 손 운영 대신 **사건 대응**(진상·주차·실수)이 손에 남는다.

### 9.2 복잡함
- **위험:** 시스템 15개가 한꺼번에 쏟아짐.
- **장치:** (1) 앱·시스템은 세계 안의 누군가가 소개할 때 생긴다(6절) = 자연스러운 튜토리얼. (2) 첫 30분에 쓰는 시스템은 8절 표에 있는 것만. (3) 모든 화면에 "이걸 하면 무엇이 바뀌나" 한 줄. (4) 숫자는 오차와 함께, 하지만 기본은 말(대사)로.

### 9.3 폰 피로
- **위험:** 작은 글씨·많은 탭·끝없는 알림.
- **장치:** 하루 푸시 3개, 결정 카드 '내일 아침에' 버튼, 두 탭 원칙, 손 운영은 큰 원형 버튼(엄지 영역), 10분 세션 끝에 "오늘은 여기까지" 요약(다음 접속 때 무엇이 기다리는지 1줄). 결폰 열린 동안 시간 정지.

### 9.4 '켜 두면 돈' 재발 (가장 중요)
- **위험:** 직원이 다 하면 방치 수익.
- **장치:**
  1. **결정 대기 정지:** 하루 마감 때 '중요' 결정 카드가 3장 이상 쌓여 있으면 다음 날로 넘어가지 않는다(자동 진행 멈춤). 켜 두면 돈이 아니라, 켜 두면 결정 대기.
  2. **위임 효율 상한:** 직원 운영은 사장 손 운영 최고 효율의 75~90%(점장 능력에 따라). 위임은 시간을 사지만 최대치는 아니다.
  3. **수익 체감과 잠식:** 같은 매장 늘리기는 상권 잠식(300m −25%)·라이벌 반응·관리 사건 증가로 한 곳당 이익이 줄어든다. 더 크려면 **다른 종류의 판단**(새 산업·도시·세계)이 필요하다.
  4. **세계가 움직인다:** 라이벌 주간 규칙·정책·사건이 가만히 있는 가게를 천천히 깎는다(예: 4주 아무 대응 없으면 라이벌 점유율 +). 처벌이 아니라 '변화'다.
  5. **돈의 한계 효용:** 큰돈은 속도만 산다. 다음 문(기회)은 사람·정보·현장 방문이 연다 → 돈이 쌓여도 할 일이 생긴다.
  6. **오프라인 진행 없음:** 앱을 닫으면 시간이 멈춘다(지금 구조 그대로). 방치 보상 자체가 없다.

### 9.5 기타
- 결정론 깨짐 → `Math.random` 금지 정적 검사. 세이브 깨짐 → 실제 v5 세이브 고정 자료로 이전 테스트. 돈 샘 → 매일 supply 검사. 성능 → 사업·라이벌은 하루·주 단위, 이름 없는 손님은 시간당 묶음 계산.

## 부록 A. 세 가지 약속을 지키는 방법

**돈 보존.** 새 돈은 새 게임 세계 생성과 v6 이전 때 새 계정 1회 자금, 두 곳에서만 생기고 `ledger.supply`에 기록된다. 그 밖의 이동(매출·광고·세금·대출·배당·투자·벌금·급여·환불)은 전부 `transfer`/`payPerson`. 도난·폐기는 재고만 줄인다. 이자·배당·보조금은 출처 계정(은행·법인·시)이 비면 지급되지 않고, 그것이 곧 경제 사건이 된다. 테스트는 매일 `Σ balances === supply`를 30일·180일 헤드리스로 확인한다.

**결정론.** `rng(seed, key)` 하나(지금 `choice()`·`weatherFor()`와 같은 FNV 계열), 키는 `종류:대상ID:날짜[:순번]`. 순회 순서·틱 크기에 의존하지 않는다(session.ts의 기존 원칙). "1분씩 진행 vs 하루 한 번에 진행" 결과가 같은지 테스트한다.

**세이브 호환.** v6 = v5 + `tycoon` 객체 하나(손님·직원 프로필·광고·계약·라이벌·사건·기회·사업·삶·정보·supply), 없으면 기본값. 기존 매물(`cafe-unit`·`shop-unit`) 숫자와 기존 플레이어 잔액은 바꾸지 않는다(세션 검증이 보증금 계정 잔액을 비교함). 새 숫자는 새 매물 ID와 새 게임에만.
